## Security Review Checklist

### Wallet Generation (viem)
- [x] Uses `generatePrivateKey()` from viem/accounts (CSPRNG)
- [x] Uses `privateKeyToAccount()` to derive address
- [x] No weak random number generation

### Private Key Encryption
- [x] Uses AES-256-GCM encryption from Story 3.1
- [x] Encryption key retrieved via `getEncryptionKey()` from env var
- [x] Private key encrypted BEFORE database storage

### No Sensitive Data Exposure
- [x] Response NEVER includes `encryptedPrivateKey` field
- [x] Error messages don't leak private key or encryption key
- [x] Console.error doesn't log private key or encryption key
- [x] Prisma select explicitly excludes encryptedPrivateKey

### Transaction Safety
- [x] Uses Prisma `$transaction` for atomicity
- [x] If encryption fails, no data is persisted
- [x] If DB update fails, automatic rollback

### Input Validation
- [x] Company ID validated from req.query
- [x] Status validation (only PENDING can be approved)
- [x] Proper error codes (404, 409, 500)
- [x] HTTP method validation (POST only)
