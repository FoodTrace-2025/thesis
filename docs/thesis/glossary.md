# Glossary

| Term | Definition |
|------|------------|
| AES-256-GCM | Advanced Encryption Standard with 256-bit key and Galois/Counter Mode; a secure encryption method used to protect stored wallet private keys. |
| Blockchain | A distributed digital ledger that records transactions across many computers, where data cannot be changed once recorded without altering all subsequent records. |
| Custodial Wallet | A wallet where a trusted third party (such as a platform server) stores and manages the private keys on behalf of the user, simplifying the user experience. |
| DApp (Decentralized Application) | An application that runs on a blockchain network rather than a single computer, using smart contracts for its backend logic. |
| Ethereum | A public blockchain platform that supports smart contracts and decentralized applications, used in this thesis for the FoodTrace system. |
| Etherscan | A web-based block explorer that allows anyone to view and verify transactions, smart contracts, and addresses on the Ethereum network. |
| EVM (Ethereum Virtual Machine) | The runtime environment that executes smart contract code on the Ethereum network, ensuring consistent behavior across all nodes. |
| Gas | A unit measuring the computational effort required to execute operations on Ethereum; users pay gas fees to compensate network validators. |
| GDPR (General Data Protection Regulation) | European Union regulation governing personal data protection, including the "right to be forgotten" which conflicts with blockchain immutability. |
| GIGO (Garbage In, Garbage Out) | A concept highlighting that blockchain can only guarantee data integrity, not accuracy; false data entered remains permanently recorded. |
| Hardhat | A JavaScript-based development environment for building, testing, and deploying Ethereum smart contracts. |
| Hybrid Storage Architecture | A design pattern storing critical data on-chain for immutability while keeping large or frequently updated data off-chain for efficiency. |
| Hyperledger Fabric | A permissioned blockchain platform designed for enterprise use, offering private channels and higher transaction throughput than public blockchains. |
| Immutability | The property of blockchain data that prevents modification or deletion once recorded, providing tamper-proof audit trails. |
| IoT (Internet of Things) | A network of physical devices with sensors that collect and transmit data; proposed for automated temperature monitoring in future work. |
| IPFS (InterPlanetary File System) | A distributed file storage system that stores data across multiple nodes, often used with blockchain to store large files off-chain. |
| Keccak-256 | The cryptographic hash function used by Ethereum to create unique fixed-length identifiers from variable-length input data. |
| Layer 2 | Scaling solutions built on top of a blockchain (Layer 1) that process transactions off the main chain to reduce costs and increase speed. |
| Mainnet | The primary production blockchain network where transactions have real economic value, as opposed to test networks. |
| MetaMask | A popular browser extension wallet that allows users to interact with Ethereum DApps and manage their cryptocurrency. |
| MVP (Minimum Viable Product) | A development approach focusing on building only essential features first to validate concepts before adding complexity. |
| Non-Custodial Wallet | A wallet where users maintain full control of their private keys, providing greater security but requiring more technical knowledge. |
| OpenZeppelin | A library of secure, audited smart contract templates including access control patterns used in the FoodTrace implementation. |
| Oracle Problem | The fundamental challenge that blockchains cannot verify the accuracy of real-world data entered into the system. |
| POC (Proof of Concept) | A prototype implementation demonstrating that a concept or approach is technically feasible before full-scale development. |
| Prisma ORM | An object-relational mapping tool that provides type-safe database access for Node.js applications using TypeScript. |
| QR Code (Quick Response Code) | A two-dimensional barcode that stores product identification data, enabling consumers to scan and retrieve supply chain information. |
| RBAC (Role-Based Access Control) | A security pattern that restricts system access based on user roles (Producer, Distributor, Retailer, Admin) rather than individual identities. |
| RPC (Remote Procedure Call) | A protocol allowing applications to request blockchain data or submit transactions through provider services like Alchemy. |
| Scalability Trilemma | The concept that blockchain systems can optimize only two of three properties: decentralization, security, and scalability. |
| Seed Phrase | A series of 12-24 words that can regenerate a wallet's private keys; losing this phrase means permanent loss of wallet access. |
| Sepolia | An Ethereum test network providing free test tokens for development and testing without real economic costs. |
| Smart Contract | Self-executing code deployed on a blockchain that automatically enforces agreement terms when predefined conditions are met. |
| Solidity | The primary programming language for writing Ethereum smart contracts, with syntax similar to JavaScript. |
| Supabase | A PostgreSQL database platform with built-in connection pooling, used for off-chain data storage in the FoodTrace system. |
| Testnet | A blockchain network for development and testing that mirrors mainnet functionality but uses tokens with no real value. |
| TPS (Transactions Per Second) | A performance metric measuring blockchain throughput; Ethereum L1 handles 15-30 TPS versus Hyperledger Fabric's 3,000+ TPS. |
| Traceability | The ability to track a product's complete journey through the supply chain from origin to consumer. |
| Transaction Hash | A unique identifier generated for each blockchain transaction, enabling verification and tracking via block explorers. |
| Wagmi | A React hooks library for Ethereum that simplifies Web3 integration, handling wallet connections and contract interactions. |
| Wallet | Software or hardware that stores cryptographic keys used to sign blockchain transactions and prove ownership of assets. |
| Web3 | The vision of a decentralized internet built on blockchain technology, where users control their own data and digital assets. |
