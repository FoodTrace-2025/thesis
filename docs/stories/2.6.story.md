# Story 2.6: Create Company Admin User API

## Status

**Draft** (Ready for implementation)

## Story

**As a** platform administrator,
**I want** to create the first COMPANY_ADMIN user for an approved company,
**so that** the company owner can manage their own employees.

## Acceptance Criteria

1. POST /api/admin/users endpoint created and functional
2. Only PLATFORM_ADMIN role can access this endpoint (requireAdmin middleware)
3. Only for APPROVED companies (returns 400 for PENDING/REJECTED)
4. User email must match company domain (email.endsWith(`@${company.domain}`))
5. User role must be COMPANY_ADMIN (cannot create other roles via this endpoint)
6. Password hashed with bcrypt (10 rounds)
7. AuditLog entry created with action "CREATE_COMPANY_ADMIN"
8. Returns 404 for non-existent company ID
9. Returns 409 if email already exists
10. Response excludes passwordHash (security)

## Tasks / Subtasks

- [ ] **Task 1: Create API Route** (AC: 1, 2)
  - [ ] Create `src/pages/api/admin/users.ts`
  - [ ] POST handler with requireAdmin middleware
  - [ ] Return 405 for non-POST methods

- [ ] **Task 2: Request Validation** (AC: 3, 4, 5)
  - [ ] Zod schema: email (required), password (min 8 chars), name (required), companyId (required)
  - [ ] Verify company exists and is APPROVED
  - [ ] Validate email domain matches company domain
  - [ ] Force role to COMPANY_ADMIN (ignore any role in request)

- [ ] **Task 3: User Creation** (AC: 6, 7)
  - [ ] Hash password with bcrypt (10 rounds)
  - [ ] Create user with Prisma in transaction
  - [ ] Create AuditLog entry in same transaction
  - [ ] Handle duplicate email (unique constraint)

- [ ] **Task 4: Response** (AC: 8, 9, 10)
  - [ ] Return 201 Created with user data
  - [ ] Exclude passwordHash from response
  - [ ] Return 404 for company not found
  - [ ] Return 409 for duplicate email

- [ ] **Task 5: Write Tests** (AC: 1-10)
  - [ ] Create `src/pages/api/admin/users.test.ts`
  - [ ] Test all success and error scenarios

### Request/Response Format

**POST /api/admin/users**

Request Body:
```json
{
  "email": "admin@producer.farm",
  "password": "SecurePass123!",
  "name": "Company Admin",
  "companyId": "test-producer-001"
}
```

Success Response (201 Created):
```json
{
  "success": true,
  "user": {
    "id": "clxyz123...",
    "email": "admin@producer.farm",
    "name": "Company Admin",
    "role": "COMPANY_ADMIN",
    "companyId": "test-producer-001",
    "createdAt": "2025-11-30T..."
  }
}
```

Error Response (400 Bad Request - Company not approved):
```json
{
  "error": "Company must be approved",
  "code": "COMPANY_NOT_APPROVED"
}
```

Error Response (400 Bad Request - Email domain mismatch):
```json
{
  "error": "Email must match company domain: producer.farm",
  "code": "INVALID_EMAIL_DOMAIN"
}
```

Error Response (404 Not Found):
```json
{
  "error": "Company not found",
  "code": "NOT_FOUND"
}
```

Error Response (409 Conflict - Duplicate email):
```json
{
  "error": "User with this email already exists",
  "code": "DUPLICATE_EMAIL"
}
```
