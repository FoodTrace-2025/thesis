# Story 2.6: Create Company Admin User API

## Status

**Draft** (Ready for implementation)

## Story

**As a** platform administrator,
**I want** to create the first COMPANY_ADMIN user for an approved company,
**so that** the company owner can manage their own employees.

## Acceptance Criteria

1. POST /api/admin/users endpoint created and functional
2. Only PLATFORM_ADMIN role can access this endpoint (requirePlatformAdmin middleware)
3. Only for APPROVED companies (returns 400 for PENDING/REJECTED)
4. User email must match company domain (email.endsWith(`@${company.domain}`))
5. User role must be COMPANY_ADMIN (cannot create other roles via this endpoint)
6. Password hashed with bcrypt (10 rounds)
7. AuditLog entry created with action "CREATE_COMPANY_ADMIN"
8. Returns 404 for non-existent company ID
9. Returns 409 if email already exists
10. Response excludes passwordHash (security)

## Tasks / Subtasks

- [ ] **Task 1: Create API Route** (AC: 1, 2)
  - [ ] Create `src/pages/api/admin/users.ts`
  - [ ] POST handler with requirePlatformAdmin middleware

- [ ] **Task 4: Response** (AC: 8, 9, 10)
  - [ ] Return 201 Created with user data
  - [ ] Exclude passwordHash from response
  - [ ] Return 404 for company not found
  - [ ] Return 409 for duplicate email

  - [ ] Test all success and error scenarios

### Request/Response Format

**POST /api/admin/users**

Request Body:
```json
{
  "email": "admin@producer.farm",
  "password": "SecurePass123!",
  "name": "Company Admin",
  "companyId": "test-producer-001"
}
```

Success Response (201 Created):
```json
{
  "success": true,
  "user": {
    "id": "clxyz123...",
    "email": "admin@producer.farm",
    "name": "Company Admin",
    "role": "COMPANY_ADMIN",
    "companyId": "test-producer-001",
    "createdAt": "2025-11-30T..."
  }
}
```

Error Response (400 Bad Request - Company not approved):
```json
{
  "error": "Company must be approved",
  "code": "COMPANY_NOT_APPROVED"
}
```

Error Response (400 Bad Request - Email domain mismatch):
```json
{
  "error": "Email must match company domain: producer.farm",
  "code": "INVALID_EMAIL_DOMAIN"
}
```

Error Response (404 Not Found):
```json
{
  "error": "Company not found",
  "code": "NOT_FOUND"
}
```

Error Response (409 Conflict - Duplicate email):
```json
{
  "error": "User with this email already exists",
  "code": "DUPLICATE_EMAIL"
}
```

### Validation Schema (src/lib/validation/user.ts)

```typescript
import { z } from 'zod';

/**
 * Schema for creating a COMPANY_ADMIN user
 * Used by POST /api/admin/users
 */
export const createCompanyAdminSchema = z.object({
  email: z.string().email('Invalid email format'),
  password: z.string().min(8, 'Password must be at least 8 characters'),
  name: z.string().min(1, 'Name is required').max(255, 'Name too long'),
  companyId: z.string().min(1, 'Company ID is required'),
});

export type CreateCompanyAdminInput = z.infer<typeof createCompanyAdminSchema>;
```

### Error Handling

| Error | Status | Response |
|-------|--------|----------|
| Validation failed | 400 | `{ error: "Validation failed", code: "VALIDATION_ERROR", details: [...] }` |
| Company not approved | 400 | `{ error: "Company must be approved", code: "COMPANY_NOT_APPROVED" }` |
| Email domain mismatch | 400 | `{ error: "Email must match company domain: {domain}", code: "INVALID_EMAIL_DOMAIN" }` |
| Company not found | 404 | `{ error: "Company not found", code: "NOT_FOUND" }` |
| Duplicate email | 409 | `{ error: "User with this email already exists", code: "DUPLICATE_EMAIL" }` |
| Not authenticated | 401 | `{ error: "Authentication required", code: "UNAUTHORIZED" }` |
| Not PLATFORM_ADMIN | 403 | `{ error: "Platform admin access required", code: "FORBIDDEN" }` |

### Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| Duplicate email bypass | Prisma unique constraint + catch P2002 error |
| Password in logs | Never log password, only hash after creation |
| Email domain bypass | Server-side validation, never trust client |
| Unauthorized access | requirePlatformAdmin middleware enforces role |
