# Story 2.7: Create Company Employee API

## Status

**Draft** (Ready for implementation)

## Story

**As a** company administrator,
**I want** to create employee user accounts for my company,
**so that** workers can access the system with appropriate roles.

## Acceptance Criteria

1. POST /api/companies/users endpoint created and functional
2. Only COMPANY_ADMIN role can access this endpoint (new middleware: requireCompanyAdmin)
3. User email must match company domain
4. User role must be one of: PRODUCER, DISTRIBUTOR, RETAILER (based on company type)
5. Cannot create PLATFORM_ADMIN or COMPANY_ADMIN via this endpoint
6. Password hashed with bcrypt (10 rounds)
7. User automatically assigned to COMPANY_ADMIN's company
8. AuditLog entry created with action "CREATE_EMPLOYEE"
9. Returns 400 for invalid role
10. Returns 409 if email already exists
11. Response excludes passwordHash

### requireCompanyAdmin Middleware

```typescript
// src/lib/auth/requireCompanyAdmin.ts
import { getServerSession } from 'next-auth';
import type { NextApiRequest, NextApiResponse } from 'next';
import { authOptions } from '@/pages/api/auth/[...nextauth]';
import { prisma } from '@/lib/prisma';

interface CompanyAdminSession {
  user: {
    id: string;
    email: string;
    role: 'COMPANY_ADMIN';
    companyId: string;
    company: {
      id: string;
      domain: string;
      type: string;
    };
  };
}

export async function requireCompanyAdmin(
  req: NextApiRequest,
  res: NextApiResponse
): Promise<CompanyAdminSession | null> {
  const session = await getServerSession(req, res, authOptions);

  if (!session?.user) {
    res.status(401).json({ error: 'Unauthorized', code: 'UNAUTHORIZED' });
    return null;
  }

  if (session.user.role !== 'COMPANY_ADMIN') {
    res.status(403).json({
      error: 'Only company administrators can access this resource',
      code: 'FORBIDDEN',
    });
    return null;
  }

  // Fetch company details
  const user = await prisma.user.findUnique({
    where: { id: session.user.id },
    include: { company: { select: { id: true, domain: true, type: true } } },
  });

  if (!user?.company) {
    res.status(403).json({
      error: 'User must belong to a company',
      code: 'NO_COMPANY',
    });
    return null;
  }

  return {
    user: {
      ...session.user,
      company: user.company,
    },
  } as CompanyAdminSession;
}
```
