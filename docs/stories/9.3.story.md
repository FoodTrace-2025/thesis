# Story 9.3: Registration Event in Timeline

## Status

**DONE** - Implemented 2025-12-14, all tests pass

## Story

**As a** consumer,
**I want** to see the product registration as the first event in the timeline,
**so that** I can see the complete journey from when the product was first recorded on the blockchain.

## Acceptance Criteria

### API Enhancement
1. GET /api/products/:id/trace-history returns registration as synthetic first event
2. Registration event appears BEFORE all TraceRecord events
3. Registration event uses data from Product table (not TraceRecord)
4. Registration event includes:
   - action: "REGISTERED"
   - location: product.origin
   - actor: { name: "Producer", company: product.company.name }
   - transactionHash: product.transactionHash
   - etherscanLink: generated from transactionHash
   - createdAt: product.createdAt

### Timeline Display
5. Registration event displays with "REGISTERED" action badge
6. Badge color is distinct (e.g., green for "created")
7. Event shows origin as location
8. Event shows producer company name
9. Event includes Etherscan link to original registration transaction

### Error Handling Enhancement
10. API returns proper 404 status for non-existent products
11. API returns proper 400 status for invalid blockchainId
12. Error responses include user-friendly message

### Technical Specifications

**API Enhancement:**

```typescript
// src/pages/api/products/[id]/trace-history.ts
// Add this to the beginning of the handler

// Fetch product with company for registration event
const product = await prisma.product.findFirst({
  where: isBlockchainId ? { blockchainId } : { id },
  include: { company: { select: { name: true } } },
});

if (!product) {
  return res.status(404).json({
    error: 'Product not found',
    code: 'NOT_FOUND',
  });
}

// Fetch trace records
const traceRecords = await prisma.traceRecord.findMany({
  where: { productId: product.id },
  orderBy: { createdAt: 'asc' },
  include: {
    user: { select: { name: true, role: true } },
    company: { select: { name: true } },
  },
});

// Create synthetic registration event
const registrationEvent = {
  id: 'registration',
  action: 'REGISTERED',
  location: product.origin,
  notes: null,
  actor: {
    name: 'Producer',
    role: 'PRODUCER',
    company: product.company.name,
  },
  transactionHash: product.transactionHash,
  etherscanLink: `https://sepolia.etherscan.io/tx/${product.transactionHash}`,
  createdAt: product.createdAt.toISOString(),
};

// Return registration as first event
const allEvents = [registrationEvent, ...formattedTraceRecords];

return res.status(200).json({
  success: true,
  traceRecords: allEvents,
  total: allEvents.length,
});
```
