# Story 2.3: Company Approve API

## Status

**Done**

## Story

**As a** platform administrator,
**I want** to approve pending companies via an API endpoint that automatically generates an Ethereum wallet,
**so that** approved companies can participate in blockchain transactions with securely stored credentials.

## Acceptance Criteria

1. POST /api/admin/companies/:id/approve endpoint created and functional
2. Only companies with status PENDING can be approved (returns 409 for APPROVED/REJECTED)
3. Wallet generated using viem (`generatePrivateKey` + `privateKeyToAccount`)
4. Private key encrypted using Story 3.1's `encryptWalletKey()` function
5. Company updated atomically: status=APPROVED, walletAddress, encryptedPrivateKey, approvedAt
6. AuditLog entry created with action "APPROVE_COMPANY" and walletAddress in details
7. Returns 404 for non-existent company ID
8. Returns 500 with rollback if wallet generation or encryption fails
9. Endpoint accessible without authentication (auth added in Story 2.5)
10. Response excludes encryptedPrivateKey (security - never expose to client)

### Viem Wallet Generation

**Using viem instead of ethers.js** (per Session 34 decision):

```typescript
import { generatePrivateKey, privateKeyToAccount } from 'viem/accounts';
import { encryptWalletKey, getEncryptionKey } from '@/lib/crypto';

// Generate wallet
const privateKey = generatePrivateKey(); // Returns 0x-prefixed hex string
const account = privateKeyToAccount(privateKey);
const walletAddress = account.address; // 0x-prefixed address

// Encrypt private key
const encryptionKey = getEncryptionKey(); // From WALLET_ENCRYPTION_KEY env var
const encryptedPrivateKey = encryptWalletKey(privateKey, encryptionKey);
```

**Why viem over ethers.js:**
- Already installed in project (v2.40.3)
- Native to Wagmi/RainbowKit ecosystem
- Smaller bundle size (~27KB vs ~130KB)
- Used in existing scripts (check-sepolia-balance.ts)

### Request/Response Format

**POST /api/admin/companies/:id/approve**

Request: No body required (company ID in URL)

Success Response (200 OK):
```json
{
  "success": true,
  "company": {
    "id": "clxyz123...",
    "name": "Hirsimaki Farm Ltd",
    "email": "contact@hirsimakifarm.fi",
    "domain": "hirsimakifarm.fi",
    "type": "PRODUCER",
    "status": "APPROVED",
    "walletAddress": "0x742d35Cc6634C0532925a3b844Bc9e7595f0bEb",
    "approvedAt": "2025-11-28T14:00:00.000Z",
    "createdAt": "2025-11-27T12:00:00.000Z"
  }
}
```

Error Response (404 Not Found):
```json
{
  "error": "Company not found",
  "code": "NOT_FOUND"
}
```

Error Response (409 Conflict):
```json
{
  "error": "Company is already approved",
  "code": "CONFLICT_ERROR"
}
```

Error Response (500 Internal Server Error):
```json
{
  "error": "Failed to approve company",
  "code": "SERVER_ERROR"
}
```

### AuditLog Entry

```typescript
await tx.auditLog.create({
  data: {
    action: 'APPROVE_COMPANY',
    companyId: company.id,
    userId: null, // Auth not implemented yet - see Story 2.5
    details: {
      walletAddress: walletAddress,
    },
  },

```

### Error Handling

| Error | Status | Response |
|-------|--------|----------|
| Company not found | 404 | `{ error: "Company not found", code: "NOT_FOUND" }` |
| Already approved | 409 | `{ error: "Company is already approved", code: "CONFLICT_ERROR" }` |
| Already rejected | 409 | `{ error: "Company was rejected", code: "CONFLICT_ERROR" }` |
| Missing WALLET_ENCRYPTION_KEY | 500 | `{ error: "Failed to approve company", code: "SERVER_ERROR" }` |
| Wallet generation failure | 500 | `{ error: "Failed to approve company", code: "SERVER_ERROR" }` |

### Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| Wallet generation fails | Transaction rollback, 500 error, admin can retry |
| Missing WALLET_ENCRYPTION_KEY | getEncryptionKey() throws clear error message |
| Race condition (double approve) | Prisma transaction + status check inside transaction |
| Private key exposed in response | Select only safe fields, never include encryptedPrivateKey |
| Private key exposed in logs | Never log privateKey or encryptionKey values |
