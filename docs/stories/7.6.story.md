# Story 7.6: Distributor Dashboard - Product List & Layout

## Status

**Done**

## Story

**As a** distributor,
**I want** to see a list of products in my company's custody on my dashboard,
**so that** I can manage and track products I am responsible for.

## Acceptance Criteria

1. Dashboard page passes userRole and companyId from session to page component
2. Dashboard fetches products from GET /api/products?owner=me on mount
3. Loading spinner displays while products are being fetched
4. Empty state displays helpful message when no products exist ("No products in custody yet")
5. Product cards display: name, origin, blockchainId, harvest date
6. Products are sorted by most recent first (createdAt desc)
7. Dashboard layout is responsive (mobile, tablet, desktop)
8. Error state displays when API call fails with retry option
9. Page title is "Distributor Dashboard"
10. User's name displays in welcome message

### Technical Specifications

**Updated getServerSideProps:**

```typescript
// src/pages/distributor/dashboard.tsx
export async function getServerSideProps(context: GetServerSidePropsContext) {
  const session = await getServerSession(context.req, context.res, authOptions);

  if (!session) {
    return { redirect: { destination: '/login', permanent: false } };
  }

  if (session.user.role !== 'DISTRIBUTOR') {
    return { redirect: { destination: '/dashboard', permanent: false } };
  }

  return {
    props: {
      userName: session.user.name || session.user.email,
      userRole: session.user.role,
      companyId: session.user.companyId,
    },
  };
}
```

**Products Fetch Pattern:**

```typescript
const [products, setProducts] = useState<Product[]>([]);
const [isLoading, setIsLoading] = useState(true);
const [error, setError] = useState<string | null>(null);

const fetchProducts = async () => {
  setIsLoading(true);
  setError(null);
  try {
    const response = await fetch('/api/products?owner=me');
    const data = await response.json();
    if (!response.ok) {
      setError(data.error || 'Failed to fetch products');
      return;
    }
    setProducts(data.products);
  } catch {
    setError('Network error. Please try again.');
  } finally {
    setIsLoading(false);
  }
};

useEffect(() => {
  fetchProducts();
}, []);
```
