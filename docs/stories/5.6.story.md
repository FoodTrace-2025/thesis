# Story 5.6: Registration Success Modal with QR Code

## Status

**Done** (Session 61 - 2025-12-04)

## Story

**As a** producer user,
**I want** to see a success modal with a visual QR code after registering a product,
**so that** I can immediately verify the registration and download/scan the QR code for product packaging.

## Acceptance Criteria

1. `react-qr-code` package installed
2. Success modal appears after successful product registration
3. Modal displays product name and blockchain ID
4. Modal displays visual QR code (scannable)
5. QR code encodes the product trace URL (e.g., `https://foodtrace.app/trace/1`)
6. Modal displays transaction hash with Etherscan link
7. Modal has "Register Another Product" button (closes modal, clears form)
8. Modal has "Go to Dashboard" button (navigates to `/producer/dashboard`)
9. Modal can be closed by clicking outside or X button
10. Modal is responsive (works on mobile)
11. QR code is sized appropriately (200x200 on desktop, 150x150 on mobile)

### Technical Specifications

**Success Modal Component:**

```typescript
// src/components/producer/RegistrationSuccessModal.tsx
import {
  Modal,
  ModalOverlay,
  ModalContent,
  ModalHeader,
  ModalBody,
  ModalFooter,
  ModalCloseButton,
  Button,
  VStack,
  Text,
  Box,
  Link as ChakraLink,
  useBreakpointValue,
} from '@chakra-ui/react';
import QRCode from 'react-qr-code';
import Link from 'next/link';

interface ProductData {
  id: string;
  blockchainId: number;
  name: string;
  origin: string;
  harvestDate: string;
  transactionHash: string;
  qrCodeUrl: string;
}

interface RegistrationSuccessModalProps {
  isOpen: boolean;
  onClose: () => void;
  product: ProductData;
  onRegisterAnother: () => void;
}

export function RegistrationSuccessModal({
  isOpen,
  onClose,
  product,
  onRegisterAnother,
}: RegistrationSuccessModalProps) {
  const qrSize = useBreakpointValue({ base: 150, md: 200 }) || 200;

  return (
    <Modal isOpen={isOpen} onClose={onClose} isCentered size="md">
      <ModalOverlay />
      <ModalContent mx={4}>
        <ModalHeader color="brand.primary">Product Registered!</ModalHeader>
        <ModalCloseButton />

        <ModalBody>
          <VStack spacing={4} align="center">
            {/* Product Info */}
            <Box textAlign="center">
              <Text fontWeight="bold" fontSize="lg">
                {product.name}
              </Text>
              <Text color="brand.muted" fontSize="sm">
                Blockchain ID: #{product.blockchainId}
              </Text>
            </Box>

            {/* QR Code */}
            <Box
              p={4}
              bg="white"
              borderRadius="md"
              border="1px solid"
              borderColor="brand.border"
            >
              <QRCode
                value={product.qrCodeUrl}
                size={qrSize}
                level="M"
              />
            </Box>
            <Text fontSize="sm" color="brand.muted">
              Scan to view product journey
            </Text>

            {/* Transaction Hash */}
            <Box textAlign="center">
              <Text fontSize="sm" color="brand.muted">
                Transaction:
              </Text>
              <ChakraLink
                href={`https://sepolia.etherscan.io/tx/${product.transactionHash}`}
                isExternal
                color="brand.accent"
                fontSize="sm"
              >
                {product.transactionHash.slice(0, 10)}...
                {product.transactionHash.slice(-8)}
              </ChakraLink>
            </Box>
          </VStack>
        </ModalBody>

        <ModalFooter>
          <VStack spacing={2} width="100%">
            <Button
              onClick={onRegisterAnother}
              width="100%"
            >
              Register Another Product
            </Button>
            <Link href="/producer/dashboard" passHref legacyBehavior>
              <Button as="a" variant="outline" width="100%">
                Go to Dashboard
              </Button>
            </Link>
          </VStack>
        </ModalFooter>
      </ModalContent>
    </Modal>
  );
}
```

### QR Code Sizing

| Viewport | Size | Rationale |
|----------|------|-----------|
| Mobile (<768px) | 150x150 | Fits small screens, still scannable |
| Desktop (>=768px) | 200x200 | Comfortable viewing, easy scanning |

| Risk | Mitigation |
|------|------------|
| QR code too small to scan | Minimum 150px, tested with phone camera |
| Modal blocks interaction | Can close with X, outside click, or buttons |
| Package adds bundle size | Only 4KB, acceptable for key feature |
