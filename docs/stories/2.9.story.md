# Story 2.9: Add Company Form

## Status

**DONE** (Session 53)

## Story

**As a** platform administrator,
**I want** to create new companies from the admin dashboard,
**so that** I can onboard B2B partners without using curl/Postman.

## Acceptance Criteria

1. "Add Company" button visible on `/admin` page header
2. Button opens modal with form fields: Name, Email, Domain, Type
3. Type dropdown shows: PRODUCER, DISTRIBUTOR, RETAILER
4. Form validates required fields before submission
5. Submit calls POST /api/admin/companies
6. Success: closes modal, refreshes company list, shows success toast
7. Error: shows error message in modal (e.g., duplicate email)
8. Cancel button closes modal without action
9. **Enhancement:** Domain auto-fills from email (read-only field)


### API Reference

**POST /api/admin/companies** (Story 2.2)

Request:
```json
{
  "name": "Company Name",
  "email": "contact@company.com",
  "domain": "company.com",
  "type": "PRODUCER"
}
```

Success Response (201):
```json
{
  "success": true,
  "company": {
    "id": "...",
    "name": "Company Name",
    "status": "PENDING",
    ...
  }
}
```

Error Response (409 - duplicate email):
```json
{
  "error": "A company with this email already exists"
}
```

### Error Handling

| Error | User Feedback |
|-------|---------------|
| Empty required field | Disable submit button |
| Duplicate email (409) | Show error in modal |
| API failure | Show error toast |
| Network error | Show error toast |

### Out of Scope

- Edit company (blockchain complications with PRODUCER_ROLE)
- Delete company (cascade complications with users/products)
- Reset to PENDING (orphaned wallet issues)
- Use Prisma Studio for test data cleanup
