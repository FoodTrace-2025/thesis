## Dev Notes

### Implementation Decisions (Made During Review)

1. **3-Second Timeout on Blockchain RPC**: Render.com has a fixed 5-second health check timeout. Added `AbortSignal.timeout(3000)` to prevent hanging.

2. **Lenient Failure Mode**: Only database errors return 500 (unhealthy). Blockchain errors/timeouts return 200 with warning (Sepolia is flaky).

3. **Modern Timeout API**: Used `AbortSignal.timeout()` instead of manual `AbortController + setTimeout` - modern best practice per MDN.

4. **Unit Test Added**: Created `health.test.ts` with 6 tests covering healthy, database error, blockchain timeout, and missing RPC URL scenarios.

5. **Node.js Engines Field**: Added `"engines": { "node": "20.x" }` to package.json. Originally planned for 18.x but upgraded due to Prisma 7.x requiring Node 20.19+.

### Technical Specifications

**Health Check Endpoint:**

```typescript
// src/pages/api/health.ts
import type { NextApiRequest, NextApiResponse } from 'next';
import { createPublicClient, http } from 'viem';
import { sepolia } from 'viem/chains';
import { prisma } from '@/lib/prisma';

interface HealthResponse {
  status: 'healthy' | 'unhealthy';
  timestamp: string;
  database: 'connected' | 'error';
  blockchain: 'connected' | 'error';
  error?: string;
}

export default async function handler(
  req: NextApiRequest,
  res: NextApiResponse<HealthResponse>
) {
  const response: HealthResponse = {
    status: 'healthy',
    timestamp: new Date().toISOString(),
    database: 'connected',
    blockchain: 'connected',
  };

  try {
    // Check database connection
    await prisma.$queryRaw`SELECT 1`;
  } catch (error) {
    response.status = 'unhealthy';
    response.database = 'error';
    response.error = `Database: ${(error as Error).message}`;
  }

  try {
    // Check blockchain RPC connection
    const publicClient = createPublicClient({
      chain: sepolia,
      transport: http(process.env.SEPOLIA_RPC_URL),
    });
    await publicClient.getBlockNumber();
  } catch (error) {
    response.status = 'unhealthy';
    response.blockchain = 'error';
    response.error = response.error
      ? `${response.error}; Blockchain: ${(error as Error).message}`
      : `Blockchain: ${(error as Error).message}`;
  }

  return res.status(response.status === 'healthy' ? 200 : 500).json(response);
}
```
