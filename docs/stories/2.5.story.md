# Story 2.5: Admin Authentication (NextAuth.js)

## Status

**Done**

## Story

**As a** platform administrator,
**I want** to authenticate with email/password before accessing admin endpoints,
**so that** only authorized users can manage companies and users.

## Acceptance Criteria

1. NextAuth.js v4 installed and configured with CredentialsProvider
2. Users can login via POST /api/auth/callback/credentials with email + password
3. Passwords verified using bcrypt (10-12 rounds)
4. JWT session strategy with 24-hour expiry
5. Session includes: userId, email, role, companyId (nullable for PLATFORM_ADMIN)
6. `requirePlatformAdmin` validates real session and PLATFORM_ADMIN role
7. Admin endpoints return 401 if not authenticated
8. Admin endpoints return 403 if authenticated but not PLATFORM_ADMIN
9. Login fails with clear error if company status is not APPROVED (for non-PLATFORM_ADMIN users)
10. Seed script creates initial PLATFORM_ADMIN user for testing

### NextAuth.js Configuration Pattern

From `docs/architecture/backend-architecture.md`:

```typescript
// pages/api/auth/[...nextauth].ts
import NextAuth from 'next-auth';
import CredentialsProvider from 'next-auth/providers/credentials';
import bcrypt from 'bcrypt';
import { prisma } from '@/lib/prisma';

export const authOptions = {
  providers: [
    CredentialsProvider({
      name: 'Email',
      credentials: {
        email: { label: "Email", type: "email" },
        password: { label: "Password", type: "password" }
      },
      async authorize(credentials) {
        if (!credentials?.email || !credentials?.password) {
          return null;
        }

        const user = await prisma.user.findUnique({
          where: { email: credentials.email },
          include: { company: true }
        });

        if (!user) return null;

        const isValid = await bcrypt.compare(credentials.password, user.passwordHash);
        if (!isValid) return null;

        // PLATFORM_ADMIN has no company, skip company check
        if (user.role !== 'PLATFORM_ADMIN' && user.company?.status !== 'APPROVED') {
          throw new Error('Company not approved');
        }

        return {
          id: user.id,
          email: user.email,
          name: user.name,
          role: user.role,
          companyId: user.companyId,
        };
      }
    })
  ],
  session: {
    strategy: 'jwt',
    maxAge: 24 * 60 * 60, // 24 hours
  },
  callbacks: {
    async jwt({ token, user }) {
      if (user) {
        token.userId = user.id;
        token.role = user.role;
        token.companyId = user.companyId;
      }
      return token;
    },
    async session({ session, token }) {
      if (session.user) {
        session.user.id = token.userId as string;
        session.user.role = token.role as string;
        session.user.companyId = token.companyId as string | null;
      }
      return session;
    }
  },
  pages: {
    signIn: '/login', // Custom login page (Epic 7)
    error: '/login',  // Redirect errors to login
  },
};

export default NextAuth(authOptions);
```

### Updated requirePlatformAdmin Pattern

```typescript
// src/lib/auth/requireAdmin.ts
import { getServerSession } from 'next-auth';
import type { NextApiRequest, NextApiResponse } from 'next';
import { authOptions } from '@/pages/api/auth/[...nextauth]';

export async function requirePlatformAdmin(
  req: NextApiRequest,
  res: NextApiResponse
) {
  const session = await getServerSession(req, res, authOptions);

  if (!session) {
    res.status(401).json({ error: 'Authentication required', code: 'UNAUTHORIZED' });
    return null;
  }

  if (session.user.role !== 'PLATFORM_ADMIN') {
    res.status(403).json({ error: 'Platform admin access required', code: 'FORBIDDEN' });
    return null;
  }

  return session;
}
```

### Error Handling

| Error | Status | Response |
|-------|--------|----------|
| No credentials | 401 | Handled by NextAuth |
| Invalid password | 401 | Handled by NextAuth |
| User not found | 401 | Handled by NextAuth |
| Company not approved | 401 | `{ error: "Company not approved" }` |
| Not authenticated | 401 | `{ error: "Authentication required", code: "UNAUTHORIZED" }` |
| Not PLATFORM_ADMIN | 403 | `{ error: "Platform admin access required", code: "FORBIDDEN" }` |

### Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| Password in logs | Never log credentials, only user.id |
| Session hijacking | JWT with 24h expiry, HTTPS in production |
| Brute force attacks | Rate limiting in production (Epic 13) |
| Missing NEXTAUTH_SECRET | Fail fast with clear error message |
