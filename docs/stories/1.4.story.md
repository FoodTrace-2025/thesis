
**Why Testnet ETH?**

- **Gas fees:** Every contract deployment and transaction costs ETH
- **Free:** Testnet ETH has no real value, unlimited from faucets
- **Safe:** Mistakes on testnet cost nothing
- **Required:** Cannot deploy to Sepolia without Sepolia ETH

### Risks & Mitigations

| Risk                              | Mitigation                                         |
| --------------------------------- | -------------------------------------------------- |
| Faucet rate limits                | Use multiple faucets, wait 24h between requests    |
| Private key exposed in Git        | .env.local in .gitignore, never commit secrets     |
| Using main wallet by mistake      | Create dedicated dev wallet, label it clearly      |
| Faucets require mainnet ETH       | Use PoW faucet (no requirements) or ask team       |
| Insufficient ETH for deployments  | Request from multiple faucets, target 1.0+ ETH     |
