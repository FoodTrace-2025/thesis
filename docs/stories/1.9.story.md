### Technical Specifications

**prisma/schema.prisma:**

```prisma
generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider  = "postgresql"
  url       = env("DATABASE_URL")
  directUrl = env("DIRECT_URL")
}

// Placeholder model - will be replaced with full schema in Epic 2
model HealthCheck {
  id        String   @id @default(uuid())
  status    String
  createdAt DateTime @default(now())
}
```

**Environment Variables (already configured):**

```bash
DATABASE_URL=postgresql://...?pgbouncer=true  # For queries (pooled)
DIRECT_URL=postgresql://...                    # For migrations (direct)
```
