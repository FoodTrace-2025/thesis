# FoodTrace Deployment Guide

## Overview

FoodTrace is deployed to Render.com using their Native Runtime (Node.js).
The production URL is: https://foodtrace.onrender.com

## Prerequisites

- Render.com account (GitHub-connected)
- Supabase database (PostgreSQL)
- Alchemy API key (Sepolia RPC)
- Smart contract deployed to Sepolia testnet

## Environment Variables

| Variable | Description | Required |
|----------|-------------|----------|
| DATABASE_URL | Supabase PostgreSQL (port 5432) | Yes |
| DIRECT_URL | Same as DATABASE_URL | Yes |
| WALLET_ENCRYPTION_KEY | 32-byte hex string | Yes |
| NEXTAUTH_SECRET | Session encryption | Yes |
| NEXTAUTH_URL | Production URL | Yes |
| NEXT_PUBLIC_PRODUCT_REGISTRY_ADDRESS | Contract address | Yes |
| SEPOLIA_RPC_URL | Alchemy RPC | Yes |
| NEXT_PUBLIC_SUPABASE_URL | Supabase URL | Yes |
| NEXT_PUBLIC_SUPABASE_ANON_KEY | Supabase anon key | Yes |
| SUPABASE_SERVICE_ROLE_KEY | Supabase service key | Yes |
| NODE_ENV | Set to "production" | Yes |

## Render.com Configuration

- **Service Type:** Web Service (Node.js)
- **Region:** Frankfurt (eu-central)
- **Plan:** Free
- **Build Command:** `npm install && npx prisma generate && npm run build`
- **Start Command:** `npm start`
- **Health Check:** `/api/health`
- **Auto-Deploy:** Enabled (main branch)

## Deployment Steps

1. Push changes to `main` branch
2. Render.com auto-deploys (or use Manual Deploy)
3. Monitor build logs in Render.com dashboard
4. Verify health check: `curl https://foodtrace.onrender.com/api/health`

## Rollback Procedure

### Via Render.com Dashboard:
1. Go to Render.com Dashboard → foodtrace service
2. Click "Deploys" tab
3. Find previous successful deploy
4. Click "Rollback" button

### Via Git:
```bash
git revert HEAD
git push origin main
# Auto-deploy will trigger with reverted code
```

## Troubleshooting

### Build Fails
- Check for missing environment variables
- Verify `npm run build` works locally
- Check Render.com build logs for specific error

### Database Connection Fails
- Verify DATABASE_URL is correct (port 5432)
- Check Supabase project is active
- Test health endpoint: returns database status

### Authentication Fails
- Verify NEXTAUTH_URL matches production URL
- Check NEXTAUTH_SECRET is set
- Clear browser cookies and retry

## Monitoring

- **Logs:** Render.com Dashboard → Logs tab
- **Health:** `GET /api/health` returns status
- **Optional:** UptimeRobot for uptime monitoring
```
