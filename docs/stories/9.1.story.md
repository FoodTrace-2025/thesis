# Story 9.1: Consumer Landing Page

## Status

**TODO** - Ready for development

## Story

**As a** consumer,
**I want** to access a landing page where I can scan a QR code or enter a product ID,
**so that** I can view the product's supply chain journey without needing an account or wallet.

## Acceptance Criteria

### Landing Page Layout
1. Page accessible at `/trace` route (public, no authentication)
2. Page title "Trace Your Food" or similar consumer-friendly heading
3. Brief explanation text: "Scan the QR code on your product or enter the Product ID to see its journey"
4. Mobile-first responsive design (works on 360px width)

### QR Scanner Section (Primary Option)
5. "Scan QR Code" button prominently displayed at top
6. Clicking button opens modal with QRScanner component
7. Reuse existing QRScanner from `src/components/scanner/QRScanner.tsx`
8. Successful scan extracts blockchainId and redirects to `/trace/{blockchainId}`
9. Scanner handles camera permission denial gracefully
10. "Cancel" button to close scanner modal

### Manual Entry Section (Fallback)
11. "Or enter Product ID manually:" label below scanner button
12. Text input field for Product ID (blockchainId)
13. "Look Up" button to trigger navigation
14. Enter key submits the form
15. Basic validation: non-empty, numeric only
16. Invalid input shows inline error message

### General
17. Use existing Layout component (no role prop = minimal header)
18. No authentication required (public page)
19. No Web3/wallet prompts
20. Touch targets minimum 44px for mobile

### Technical Specifications

**Page Component:**

```typescript
// src/pages/trace/index.tsx
import { useState } from 'react';
import { useRouter } from 'next/router';
import {
  Box,
  VStack,
  Heading,
  Text,
  Button,
  Input,
  HStack,
  Modal,
  ModalOverlay,
  ModalContent,
  ModalHeader,
  ModalCloseButton,
  ModalBody,
  useDisclosure,
  FormControl,
  FormErrorMessage,
} from '@chakra-ui/react';
import { ViewIcon } from '@chakra-ui/icons';
import { Layout } from '@/components/layout';
import { QRScanner } from '@/components/scanner';

export default function ConsumerLandingPage() {
  const router = useRouter();
  const { isOpen, onOpen, onClose } = useDisclosure();
  const [productId, setProductId] = useState('');
  const [error, setError] = useState('');

  const handleScan = (id: string) => {
    onClose();
    router.push(`/trace/${id}`);
  };

  const handleManualLookup = () => {
    setError('');
    const trimmed = productId.trim();

    if (!trimmed) {
      setError('Please enter a Product ID');
      return;
    }

    if (!/^\d+$/.test(trimmed)) {
      setError('Product ID must be a number');
      return;
    }

    router.push(`/trace/${trimmed}`);
  };

  return (
    <Layout>
      <VStack spacing={8} maxW="md" mx="auto" py={8} px={4}>
        <Heading color="brand.primary" textAlign="center">
          Trace Your Food
        </Heading>
        <Text color="brand.muted" textAlign="center">
          Scan the QR code on your product or enter the Product ID to see its journey from farm to table.
        </Text>

        {/* QR Scanner Button */}
        <Button
          size="lg"
          colorScheme="green"
          leftIcon={<ViewIcon />}
          onClick={onOpen}
          w="full"
        >
          Scan QR Code
        </Button>

        {/* Divider */}
        <Text color="brand.muted">— or —</Text>

        {/* Manual Entry */}
        <FormControl isInvalid={!!error}>
          <Text color="brand.muted" mb={2}>
            Enter Product ID manually:
          </Text>
          <HStack>
            <Input
              placeholder="e.g., 1"
              value={productId}
              onChange={(e) => setProductId(e.target.value)}
              onKeyDown={(e) => e.key === 'Enter' && handleManualLookup()}
            />
            <Button colorScheme="green" onClick={handleManualLookup}>
              Look Up
            </Button>
          </HStack>
          {error && <FormErrorMessage>{error}</FormErrorMessage>}
        </FormControl>
      </VStack>

      {/* QR Scanner Modal */}
      <Modal isOpen={isOpen} onClose={onClose} size="lg">
        <ModalOverlay />
        <ModalContent>
          <ModalHeader>Scan Product QR Code</ModalHeader>
          <ModalCloseButton />
          <ModalBody pb={6}>
            <QRScanner onScan={handleScan} />
          </ModalBody>
        </ModalContent>
      </Modal>
    </Layout>
  );
}
```
