# Story 9.1: Consumer Landing Page

## Status

**TODO** - Ready for development

## Story

**As a** consumer,
**I want** to access a landing page where I can scan a QR code or enter a product ID,
**so that** I can view the product's supply chain journey without needing an account or wallet.

## Acceptance Criteria

### Landing Page Layout
1. Page accessible at `/trace` route (public, no authentication)
2. Page title "Trace Your Food" or similar consumer-friendly heading
3. Brief explanation text: "Scan the QR code on your product or enter the Product ID to see its journey"
4. Mobile-first responsive design (works on 360px width)

### QR Scanner Section (Primary Option)
5. “Scan” icon (camera) displayed as the primary trigger next to the input
6. Tapping the icon opens modal with QRScanner component
7. Reuse existing QRScanner from `src/components/scanner/QRScanner.tsx`
8. Successful scan extracts blockchainId and redirects to `/trace/{blockchainId}`
9. Scanner handles camera permission denial gracefully
10. Modal includes a clear close control (e.g., “Cancel” or close button) to dismiss the scanner

### Manual Entry Section (Fallback)
11. Text input field for Product ID (blockchainId)
12. "Search" button to trigger navigation
13. Enter key submits the form
14. Basic validation: non-empty; validate existence via API; show inline error.
15. Invalid input shows inline error message

### General
16. Create and use ConsumerLayout (src/components/layout/ConsumerLayout.tsx) for the public page (minimal header).
17. No authentication required (public page)
18. No Web3/wallet prompts
19. Touch targets minimum 44px for mobile

### Technical Specifications

**Page Component:**

```typescript
// src/pages/trace/index.tsx
import { useState } from "react";
import { useRouter } from "next/router";
import {
  Box,
  Text,
  VStack,
  Modal,
  ModalOverlay,
  ModalContent,
  ModalBody,
  ModalCloseButton,
  FormControl,
  FormErrorMessage,
} from "@chakra-ui/react";
import { ConsumerLayout } from "@/components/layout/ConsumerLayout";
import { SearchBarWithScan } from "@/components/scanner/SearchBarWithScan";
import { QRScanner } from "@/components/scanner/QRScanner";

export default function TraceEntryPage() {
  const router = useRouter();
  const [productId, setProductId] = useState("");
  const [error, setError] = useState("");
  const [showScanner, setShowScanner] = useState(false);

  const handleManualLookup = async () => {
    const trimmed = productId.trim();
    if (!trimmed) {
      setError("Enter a product ID to continue.");
      return;
    }
    try {
      const res = await fetch(`/api/products/${trimmed}`);
      if (!res.ok) {
        setError("Product not found. Check the ID on the package.");
        return;
      }
      setError("");
      router.push(`/trace/${trimmed}`);
    } catch {
      setError("Network issue. Please try again.");
    }
  };

  const handleScanSuccess = (id: string) => {
    setShowScanner(false);
    setError("");
    router.push(`/trace/${id}`);
  };

  return (
    <ConsumerLayout>
      <Box mb={6} textAlign="center">
        <Text fontSize="sm" color="brand.muted">
          Scan the QR code on the package or search by product ID
        </Text>
      </Box>

      <VStack align="stretch" spacing={2}>
        <SearchBarWithScan
          value={productId}
          onChange={(val) => {
            setProductId(val);
            if (error) setError("");
          })
          onSearch={handleManualLookup}
          onScanClick={() => setShowScanner(true)} // scan icon opens modal
        />

        <FormControl isInvalid={!!error}>
          {error ? (
            <FormErrorMessage>{error}</FormErrorMessage>
          ) : (
            <Text fontSize="sm" color="brand.muted">
              Tip: Product ID is printed under the QR code.
            </Text>
          )}
        </FormControl>
      </VStack>

      <Modal isOpen={showScanner} onClose={() => setShowScanner(false)} isCentered>
        <ModalOverlay />
        <ModalContent maxW="480px" mx={4} p={2}>
          <ModalCloseButton />
          <ModalBody pb={4}>
            <QRScanner
              onScan={handleScanSuccess}
              onError={(err) => setError(err.message)}
            />
          </ModalBody>
        </ModalContent>
      </Modal>
    </ConsumerLayout>
  );
}
```
