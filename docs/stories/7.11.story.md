# Story 7.11: SOLD Ownership Transfer Fix

## Status

**Complete** (2025-12-05)

## Story

**As a** system,
**I want** to set `currentOwnerId` to null when a product is marked as SOLD,
**so that** sold products automatically leave the "Products in Custody" view and the data model accurately reflects that the product has left the supply chain.

## Background

Currently, when a SOLD trace record is added, the `currentOwnerId` remains unchanged (still points to the retailer). This causes:
1. SOLD products to appear in "Products in Custody" lists
2. Confusion about whether the product is still in inventory
3. Need for manual filtering to separate sold from active products

This fix ensures `currentOwnerId = null` means "product has left the supply chain to consumer".

## Acceptance Criteria

### API Changes
1. POST /api/products/:id/trace updates `currentOwnerId` to null when action is SOLD
2. Existing RECEIVED ownership transfer logic unchanged (still sets to company.id)
3. Audit log captures ownership change to null with reason "SOLD"
4. Products with `currentOwnerId = null` excluded from `owner=me` queries automatically

### Data Integrity
5. SOLD products still appear in `company=me` queries (Producer's registered products)
6. SOLD products still appear in trace history queries
7. TraceTimeline component continues to work for sold products

### No Regression
8. All existing trace API tests pass
9. Ownership transfer on RECEIVED still works correctly
10. Products list API returns correct results for both filters

### Technical Specifications

**Code Change in trace.ts:**

```typescript
// Current (lines 288-294):
if (action === 'RECEIVED') {
  await tx.product.update({
    where: { id: product.id },
    data: { currentOwnerId: company.id },
  });
}

// New (add after RECEIVED block):
if (action === 'RECEIVED') {
  await tx.product.update({
    where: { id: product.id },
    data: { currentOwnerId: company.id },
  });
} else if (action === 'SOLD') {
  await tx.product.update({
    where: { id: product.id },
    data: { currentOwnerId: null },
  });
}
```

**Audit Log Enhancement:**

```typescript
// In the audit log creation (lines 296-316), update details:
details: {
  // ... existing fields ...
  ownershipTransferred: action === 'RECEIVED' || action === 'SOLD',
  previousOwnerId: (action === 'RECEIVED' || action === 'SOLD') ? product.currentOwnerId : undefined,
  newOwnerId: action === 'RECEIVED' ? company.id : (action === 'SOLD' ? null : undefined),
  soldToConsumer: action === 'SOLD',
},
```
