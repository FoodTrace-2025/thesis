### Technical Specifications

**Why This Migration Is Necessary:**

`bcrypt` is a native Node.js module that requires C++ compilation during `npm install`. This can fail on:
- Render.com build environment (missing build tools)
- Different Node.js versions
- Alpine Linux-based Docker images

`bcryptjs` is a pure JavaScript implementation that:
- Works identically to bcrypt (same API)
- No native compilation required
- Slightly slower but acceptable for POC

**Import Change Pattern:**

```typescript
// Before
import bcrypt from 'bcrypt';

// After
import bcrypt from 'bcryptjs';
```

**Verification Commands:**

```bash
# Remove bcrypt, add bcryptjs
npm uninstall bcrypt
npm install bcryptjs
npm install -D @types/bcryptjs

# Verify no other files use bcrypt
grep -r "from 'bcrypt'" src/
grep -r 'require.*bcrypt' src/

# Build and test
npm run build
npm run test
```
