# Story 7.17: Incoming Shipments Visibility

## Status

**Draft** (2025-12-05)

## Story

**As a** distributor or retailer,
**I want** to see incoming shipments on my dashboard without manually searching by product ID,
**so that** I can easily accept products being shipped to me and have a smoother receiving workflow.

## Background

Currently, when a distributor marks a product as SHIPPED, the receiving party (retailer or another distributor) has no visibility of the incoming product. They must:
1. Know the product ID through external communication
2. Manually enter the ID in the "Receive New Product" search
3. Add a RECEIVED trace

This creates poor UX and makes the demo flow awkward. Users expect incoming shipments to appear automatically.

## Acceptance Criteria

### Schema Changes
1. TraceRecord model extended with optional `recipientCompanyId` field
2. Field only populated for SHIPPED action
3. Migration runs without data loss

### SHIPPED Action Enhancement
4. SHIPPED trace form includes "Ship to" company selector
5. Company selector shows approved companies of appropriate type (Distributor/Retailer)
6. `recipientCompanyId` saved with SHIPPED trace record

### Dashboard Updates
7. Distributor dashboard shows "Incoming Shipments" section
8. Retailer dashboard shows "Incoming Shipments" section
9. Incoming shipments query: Products where last trace is SHIPPED AND recipientCompanyId = me
10. Each incoming shipment shows product info and "Accept" button

### Accept Workflow
11. "Accept" button opens pre-filled RECEIVED form
12. Location field pre-populated with user's company default or editable
13. Submitting creates RECEIVED trace (existing flow)
14. Product moves from "Incoming" to "In Custody" after acceptance

### Edge Cases
15. Products shipped to wrong company don't appear in incoming
16. Already-received products don't appear in incoming
17. Loading and error states handled

### Technical Specifications

**Schema Change:**

```prisma
model TraceRecord {
  // ... existing fields ...

  // Story 7.17: Incoming shipments - who is receiving this shipment?
  recipientCompanyId String?
  recipientCompany   Company? @relation("ShipmentRecipient", fields: [recipientCompanyId], references: [id])
}

model Company {
  // ... existing relations ...
  incomingShipments  TraceRecord[] @relation("ShipmentRecipient")
}
```

**Incoming Query Logic:**

```typescript
// GET /api/products?incoming=me
// Returns products where:
// 1. Last trace action is SHIPPED
// 2. That SHIPPED trace has recipientCompanyId = session.companyId
// 3. No subsequent RECEIVED trace exists from me

const incomingProducts = await prisma.product.findMany({
  where: {
    traceRecords: {
      some: {
        action: 'SHIPPED',
        recipientCompanyId: session.user.companyId,
        // No RECEIVED by me after this SHIPPED
      },
    },
  },
});
```
