# Story 7.16: Producer Dashboard Labels and Status Display

## Status

**Draft** (2025-12-05)

## Story

**As a** producer,
**I want** to see clear labels and status information for my registered products,
**so that** I understand the current state of products I created as they move through the supply chain.

## Background

The producer dashboard currently shows "Registered Products" but lacks:
1. Clear section label indicating these are products the producer created
2. Status badges showing current state (In Stock, Sold, etc.)
3. Clear indication of which company currently holds each product

This story updates labels and adds status display without adding tabs (producer has simpler needs).

## Acceptance Criteria

### Label Updates
1. Section heading updated to "My Registered Products"
2. Empty state message updated: "No products registered yet. Click 'Register New Product' to add your first product."

### Status Display
3. Each product card shows StatusBadge component (IN_STOCK or SOLD)
4. Each product card shows "Current Owner: {company name}" clearly
5. Products with null owner show "Current Owner: Sold to Consumer"

### Action Button Logic
6. "Add Trace" button shown only if producer still owns the product
7. "View Timeline" button always visible for all products

### API Integration
8. Dashboard fetches from `company=me` endpoint (existing)
9. Products include status field from API (Story 7.12)

### Why No Tabs for Producer?

Unlike distributors and retailers, producers have a simpler mental model:
- They care about "products I created"
- They track where those products went (via current owner display)
- They don't need to separate "in custody" vs "transferred" - the status badge and current owner text provide this info

Adding tabs would over-complicate the producer UX. The single list with status badges is sufficient.

### Risks & Mitigations

| Current owner not updating | Refetch products after trace added |
