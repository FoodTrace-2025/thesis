# Story 7.5: TraceRecordForm + TraceTimeline Components

## Status

**DONE** - Implementation complete

## Story

**As a** frontend developer,
**I want** reusable TraceRecordForm and TraceTimeline components,
**so that** distributor and retailer dashboards can add and view trace records consistently.

## Acceptance Criteria

### TraceRecordForm Component
1. Component accepts productId, userRole, and onSuccess callback as props
2. Action dropdown shows role-filtered options (see Role-Action Mapping below)
3. Location input field (required, max 100 characters)
4. Notes textarea field (optional, max 500 characters)
5. Client-side Zod validation before API submission
6. Loading state during blockchain transaction (15-30 second wait message)
7. Submit button disabled during loading
8. Toast notification on success with Etherscan link
9. Toast notification on error with message
10. Form clears after successful submission

### TraceTimeline Component
11. Component accepts productId as prop
12. Fetches from GET /api/products/:id/trace-history on mount
13. Shows loading spinner while fetching
14. Empty state with helpful message when no trace records
15. Displays trace records in vertical timeline (oldest first)
16. Each record shows: action, location, actor name, company, timestamp
17. Each record includes clickable Etherscan link
18. Mobile-responsive layout (works on phone/tablet/desktop)

### General
19. Components use Chakra UI directly (no wrapper components)
20. Components follow existing project patterns (ProductRegistrationForm reference)
21. Unit tests achieve >70% code coverage

## Role-Action Mapping

Based on supply chain workflow and UX best practices (filter dropdown by user role):

| Role | Available Actions | Rationale |
|------|------------------|-----------|
| PRODUCER | QUALITY_CHECK, SHIPPED | Creates product, doesn't receive |
| DISTRIBUTOR | RECEIVED, QUALITY_CHECK, SHIPPED | Receives from producer, ships to retailer |
| RETAILER | RECEIVED, QUALITY_CHECK, STOCKED, SOLD | Receives from distributor, sells to consumer |
