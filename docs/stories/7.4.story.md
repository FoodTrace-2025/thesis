# Story 7.4: Product Ownership Tracking

## Status

**Complete** - All tasks done, 196 tests pass (22 new), 100% coverage for products/index.ts

## Story

**As a** supply chain system,
**I want** to track product ownership through the supply chain,
**so that** dashboards show only products currently in each company's custody.

## Acceptance Criteria

1. Add `currentOwnerId` field to Product model (nullable String, references Company)
2. Add `currentOwner` relation to Product model
3. Update product registration API to set `currentOwnerId` = producer's companyId on creation
4. Update POST /api/products/:id/trace: when action="RECEIVED", set `currentOwnerId` = caller's companyId
5. Create GET /api/products endpoint
6. Support `?owner=me` query parameter (requires authentication)
7. Return 401 if `?owner=me` used without valid session
8. Return products filtered by user's companyId when `?owner=me`
9. Return all registered products when no filter (public access)
10. Include pagination support (limit: 1-100 default 50, offset: min 0 default 0)
11. Response includes: id, name, origin, blockchainId, currentOwner.name, createdAt
12. Return 405 for non-GET methods on products list endpoint
13. Unit tests achieve >70% code coverage

**Ownership Transfer Logic:**

Per supply chain "chain of custody" best practices:

| Action | Triggers Transfer? | Reason |
|--------|-------------------|--------|
| RECEIVED | Yes | Confirms physical custody taken |
| QUALITY_CHECK | No | Inspection only |
| SHIPPED | No | Sender still owns until received |
| STOCKED | No | Already owns |
| SOLD | No | Keep retailer as owner |

**Products List API (src/pages/api/products/index.ts):**

```typescript
// GET /api/products?owner=me&limit=50&offset=0
import type { NextApiRequest, NextApiResponse } from 'next';
import { getServerSession } from 'next-auth';
import { z } from 'zod';
import { prisma } from '@/lib/prisma';
import { authOptions } from '@/pages/api/auth/[...nextauth]';

const querySchema = z.object({
  owner: z.enum(['me']).optional(),
  limit: z.coerce.number().int().min(1).max(100).default(50),
  offset: z.coerce.number().int().min(0).default(0),
});

export default async function handler(req: NextApiRequest, res: NextApiResponse) {
  if (req.method !== 'GET') {
    return res.status(405).json({ error: 'Method not allowed' });
  }

  const validation = querySchema.safeParse(req.query);
  if (!validation.success) {
    return res.status(400).json({ error: 'Invalid parameters', details: validation.error.issues });
  }

  const { owner, limit, offset } = validation.data;

  // If owner=me, require authentication
  if (owner === 'me') {
    const session = await getServerSession(req, res, authOptions);
    if (!session?.user?.companyId) {
      return res.status(401).json({ error: 'Authentication required', code: 'UNAUTHORIZED' });
    }

    const [products, total] = await Promise.all([
      prisma.product.findMany({
        where: { currentOwnerId: session.user.companyId },
        include: { currentOwner: { select: { name: true } } },
        take: limit,
        skip: offset,
        orderBy: { createdAt: 'desc' },
      }),
      prisma.product.count({ where: { currentOwnerId: session.user.companyId } }),
    ]);

    return res.status(200).json({ success: true, products, total, limit, offset });
  }

  // Public: return all products
  const [products, total] = await Promise.all([
    prisma.product.findMany({
      include: { currentOwner: { select: { name: true } } },
      take: limit,
      skip: offset,
      orderBy: { createdAt: 'desc' },
    }),
    prisma.product.count(),
  ]);

  return res.status(200).json({ success: true, products, total, limit, offset });
}
```
