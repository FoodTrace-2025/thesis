# Story 7.10: QR Scanner Component

## Status

**Done** (2025-12-05)

## Story

**As a** distributor or retailer,
**I want** to scan a product's QR code with my device camera,
**so that** I can quickly look up products without manually typing the product ID.

## Acceptance Criteria

### QR Scanner Component
1. QRScanner component created using html5-qrcode library
2. Component requests camera permission on mount
3. Permission denied state shows helpful message with instructions
4. No camera available state shows appropriate message
5. Scanner displays live camera feed with scanning region overlay
6. Successful scan calls onScan callback with decoded product ID
7. Scanner automatically stops after successful scan
8. Component cleans up camera resources on unmount

### Integration
9. Distributor dashboard "Receive Product" section includes "Scan QR Code" button
10. Retailer dashboard "Receive Product" section includes "Scan QR Code" button
11. Clicking "Scan QR Code" opens modal with QRScanner component
12. Successful scan auto-fills product ID and triggers lookup
13. User can close scanner modal and use manual ID entry as fallback

### Mobile Support
14. Scanner works on mobile devices (iOS Safari, Android Chrome)
15. Scanner uses back camera by default on mobile devices
16. Scanner UI is touch-friendly and works in portrait/landscape

### Technical Specifications

**QRScanner Component:**

```typescript
// src/components/scanner/QRScanner.tsx
import { useEffect, useRef, useState } from 'react';
import { Html5Qrcode } from 'html5-qrcode';
import { Box, Text, Button, Center, VStack, Alert, AlertIcon } from '@chakra-ui/react';

interface QRScannerProps {
  onScan: (productId: string) => void;
  onError?: (error: string) => void;
}

export function QRScanner({ onScan, onError }: QRScannerProps) {
  const [permissionDenied, setPermissionDenied] = useState(false);
  const [noCamera, setNoCamera] = useState(false);
  const [isScanning, setIsScanning] = useState(false);
  const scannerRef = useRef<Html5Qrcode | null>(null);
  const elementId = 'qr-reader';

  useEffect(() => {
    const scanner = new Html5Qrcode(elementId);
    scannerRef.current = scanner;

    const startScanner = async () => {
      try {
        await scanner.start(
          { facingMode: 'environment' }, // Back camera on mobile
          {
            fps: 10,
            qrbox: { width: 250, height: 250 },
          },
          (decodedText) => {
            // Extract product ID from QR code URL
            // Format: https://foodtrace.app/trace/{productId}
            const match = decodedText.match(/\/trace\/(\d+)/);
            const productId = match ? match[1] : decodedText;

            scanner.stop();
            setIsScanning(false);
            onScan(productId);
          },
          () => {} // Ignore scan errors (continuous scanning)
        );
        setIsScanning(true);
      } catch (err: any) {
        if (err.name === 'NotAllowedError') {
          setPermissionDenied(true);
        } else if (err.name === 'NotFoundError') {
          setNoCamera(true);
        } else {
          onError?.(err.message || 'Failed to start camera');
        }
      }
    };

    startScanner();

    return () => {
      if (scannerRef.current?.isScanning) {
        scannerRef.current.stop().catch(() => {});
      }
    };
  }, [onScan, onError]);

  if (permissionDenied) {
    return (
      <Center p={8}>
        <VStack spacing={4}>
          <Alert status="warning" borderRadius="md">
            <AlertIcon />
            Camera permission denied
          </Alert>
          <Text textAlign="center" color="brand.muted">
            Please allow camera access in your browser settings to scan QR codes.
          </Text>
          <Button onClick={() => window.location.reload()}>
            Try Again
          </Button>
        </VStack>
      </Center>
    );
  }

  if (noCamera) {
    return (
      <Center p={8}>
        <VStack spacing={4}>
          <Alert status="info" borderRadius="md">
            <AlertIcon />
            No camera found
          </Alert>
          <Text textAlign="center" color="brand.muted">
            No camera detected on this device. Please use manual product ID entry.
          </Text>
        </VStack>
      </Center>
    );
  }

  return (
    <Box>
      <Box id={elementId} width="100%" />
      {isScanning && (
        <Text textAlign="center" mt={4} color="brand.muted">
          Point camera at product QR code
        </Text>
      )}
    </Box>
  );
}
```

**Modal Integration in Dashboard:**

```typescript
import { QRScanner } from '@/components/scanner';

const [isScannerOpen, setIsScannerOpen] = useState(false);

const handleScan = (productId: string) => {
  setIsScannerOpen(false);
  setLookupId(productId);
  handleLookup(productId); // Auto-lookup after scan
};

// In receive section:
<HStack spacing={4}>
  <Input
    value={lookupId}
    onChange={(e) => setLookupId(e.target.value)}
    placeholder="Enter Product ID"
  />
  <Button onClick={() => handleLookup(lookupId)}>Look Up</Button>
  <Button onClick={() => setIsScannerOpen(true)} leftIcon={<ViewIcon />}>
    Scan QR
  </Button>
</HStack>

<Modal isOpen={isScannerOpen} onClose={() => setIsScannerOpen(false)} size="lg">
  <ModalOverlay />
  <ModalContent>
    <ModalHeader>Scan Product QR Code</ModalHeader>
    <ModalCloseButton />
    <ModalBody pb={6}>
      <QRScanner onScan={handleScan} />
    </ModalBody>
  </ModalContent>
</Modal>
```

### QR Code Format

Products generate QR codes with URL format:
```
https://foodtrace.app/trace/{blockchainId}
```

Scanner extracts `blockchainId` from URL and uses it for product lookup.

### Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| iOS Safari quirks | Test on real device, use facingMode instead of deviceId |
| Camera stays active after modal close | useEffect cleanup stops camera |
| QR code URL format mismatch | Fallback: use raw decoded text if URL pattern not found |
| User denies permission repeatedly | Clear instructions, manual entry fallback always available |
