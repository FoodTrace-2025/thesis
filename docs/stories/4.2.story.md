# Story 4.2: Login Page UI

## Status

**Draft**

## Story

**As a** user (Producer, Distributor, Retailer, or Platform Admin),
**I want** a clean, responsive login page,
**so that** I can authenticate and access my role-specific dashboard.

## Acceptance Criteria

1. Login page created at `/login` route
2. Email and password input fields with proper labels
3. "Login" button submits form (connected to NextAuth signIn)
4. "Remember me" checkbox (UI only for POC)
5. "Forgot password" link (UI only, non-functional for POC)
6. Role information cards showing the 4 supply chain roles (illustrative)
7. Responsive layout (mobile-first, works on all screen sizes)
8. All colors use theme tokens (no hardcoded hex values)
9. Error states displayed for invalid credentials
10. Loading state shown during authentication

### Technical Specifications

**NextAuth Integration:**

```typescript
// src/pages/login.tsx
import { signIn } from 'next-auth/react';
import { useState } from 'react';
import { useRouter } from 'next/router';

export default function LoginPage() {
  const [email, setEmail] = useState('');
  const [password, setPassword] = useState('');
  const [error, setError] = useState('');
  const [isLoading, setIsLoading] = useState(false);
  const router = useRouter();

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    setIsLoading(true);
    setError('');

    const result = await signIn('credentials', {
      email,
      password,
      redirect: false,
    });

    setIsLoading(false);

    if (result?.error) {
      setError('Invalid email or password');
    } else {
      router.push('/dashboard'); // Or role-specific redirect
    }
  };

  // ... render form
}
```
