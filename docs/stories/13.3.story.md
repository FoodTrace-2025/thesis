### Technical Specifications

**Environment Variables Reference:**

| Variable | Description | Source |
|----------|-------------|--------|
| DATABASE_URL | `postgresql://postgres.xxx:password@aws-1-eu-west-1.pooler.supabase.com:5432/postgres` | .env.local |
| DIRECT_URL | Same as DATABASE_URL | .env.local |
| WALLET_ENCRYPTION_KEY | 32-byte hex string | .env.local |
| NEXTAUTH_SECRET | Base64 encoded secret | .env.local |
| NEXTAUTH_URL | `https://foodtrace.onrender.com` | Production URL |
| NEXT_PUBLIC_PRODUCT_REGISTRY_ADDRESS | `0x5d56f5a8703d7d545319177042cd91FD3339E2b6` | .env.local |
| SEPOLIA_RPC_URL | `https://eth-sepolia.g.alchemy.com/v2/xxx` | .env.local |
| PRIVATE_KEY | Deployer wallet key for granting blockchain roles | .env.local |
| NEXT_PUBLIC_BASE_URL | `https://foodtrace.onrender.com` | Production URL |

**Note:** NODE_VERSION=20 is set in Render.com (not in .env.render) to specify the Node.js runtime version.

**Important Notes:**

1. **Use Direct Connection (Port 5432):** Not pgBouncer (port 6543). Direct connection is simpler and sufficient for POC traffic.

2. **WALLET_ENCRYPTION_KEY Must Match:** Use the SAME key as development. If different, existing encrypted wallets cannot be decrypted.

3. **NEXTAUTH_URL:** Update to match the actual Render.com URL assigned. This is critical for authentication callbacks.

4. **NEXT_PUBLIC_ Variables:** These are embedded in the client bundle at build time. If changed, rebuild is required.

| Cold start slow (30-60s) | Expected for free tier; keep tab open before demo |
