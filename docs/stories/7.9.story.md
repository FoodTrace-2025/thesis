# Story 7.9: Producer Dashboard - Trace Features

## Status

**Done**

## Story

**As a** producer,
**I want** to add trace records and view trace history for products I registered,
**so that** I can document quality checks and shipping, and track where my products go.

## Acceptance Criteria

### Product List
1. Dashboard displays list of products registered by producer's company
2. Products fetched from GET /api/products?owner=me
3. Loading and error states handled
4. Existing "Register New Product" button preserved

### Trace Features
5. Each product card has "Add Trace Record" button
6. TraceRecordForm shows PRODUCER actions: QUALITY_CHECK, SHIPPED
7. Each product card has "View Timeline" button
8. TraceTimeline displays inline when expanded
9. Timeline shows full product journey (including distributor/retailer records)

### Producer-Specific
10. No "Receive Product" section (producers create products, don't receive them)
11. Page maintains existing layout with product registration CTA

### Technical Specifications

**Key Differences from Distributor/Retailer Dashboards:**

```typescript
// 1. TraceRecordForm receives PRODUCER role
<TraceRecordForm
  productId={selectedProductId}
  userRole="PRODUCER"  // Shows: QUALITY_CHECK, SHIPPED only
  onSuccess={handleTraceSuccess}
/>

// 2. NO "Receive Product" section
// Producers create products, they don't receive them

// 3. Keep existing "Register New Product" button
<Box>
  <Button as={NextLink} href="/producer/register" size="lg">
    Register New Product
  </Button>
</Box>

// 4. Add products list below
<Box mt={8}>
  <Heading size="md" mb={4}>My Products</Heading>
  <SimpleGrid columns={{ base: 1, md: 2, lg: 3 }} spacing={4}>
    {products.map((product) => (
      <ProductCard key={product.id} product={product} ... />
    ))}
  </SimpleGrid>
</Box>
```

**Role-Action Mapping:**

| Role | Available Actions |
|------|------------------|
| **PRODUCER** | **QUALITY_CHECK, SHIPPED** |
| DISTRIBUTOR | RECEIVED, QUALITY_CHECK, SHIPPED |
| RETAILER | RECEIVED, QUALITY_CHECK, STOCKED, SOLD |

### Key Decisions

1. **`company=me` filter** - Uses companyId (registration) instead of currentOwnerId (ownership) so producers see all their registered products regardless of current ownership
2. **Ownership-based UI** - "Add Trace" button hidden when product ownership has transferred
3. **No "Receive Product" section** - Producers create products, they don't receive them
