### Reference Information

**From Epic 1 (docs/prd/epic-1-project-setup.md):**

- Supabase provides built-in pgBouncer connection pooling
- Port 6543 = pooled connection (USE THIS)
- Port 5432 = direct connection (avoid for web apps)
- Connection pooling is CRITICAL for Next.js serverless functions

**Required Environment Variable Format:**

```bash
DATABASE_URL="postgresql://postgres.[project-ref]:[password]@aws-0-[region].pooler.supabase.com:6543/postgres?pgbouncer=true"
```

**Why Supabase?**

- Free tier sufficient for thesis POC
- Built-in pgBouncer prevents connection exhaustion
- PostgreSQL compatible with Prisma ORM
- Real-time features available if needed later

### Risks & Mitigations

| Risk                                | Mitigation                                  |
| ----------------------------------- | ------------------------------------------- |
| Forgot database password            | Save immediately when creating project      |
| Wrong connection string (port 5432) | Always use port 6543 for pooled connections |
| Credentials lost                    | Store in password manager with backup       |
