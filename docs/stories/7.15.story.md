# Story 7.15: Retailer Dashboard Tabs

## Status

**Draft** (2025-12-05)

## Story

**As a** retailer,
**I want** to switch between "In Stock", "Sold", and "Product History" views,
**so that** I can manage my current inventory, review sold items, and see my complete handling history.

## Background

Retailers have an additional need beyond distributors: tracking sold products separately from in-stock inventory. This story adds three tabs:
- **In Stock (N)**: Products I currently own AND not sold
- **Sold (M)**: Products I sold (last action was SOLD by me)
- **Product History (P)**: All products I've ever touched

## Acceptance Criteria

### Tab Navigation
1. Three tabs displayed: "In Stock", "Sold", "Product History"
2. Each tab shows count badge with number of items
3. "In Stock" tab selected by default on page load
4. Clicking tab switches content without full page reload
5. Tab styling follows Chakra UI Tabs component patterns

### In Stock Tab
6. Shows products where `currentOwnerId = myCompany` (owner=me)
7. Excludes products where last trace action is SOLD
8. Products include status badge (always "In Stock" in this tab)
9. "Add Trace" button visible
10. Empty state: "No products in stock yet"

### Sold Tab
11. Shows products where my company performed SOLD action
12. Query: Products from `history=me` filtered by last action = SOLD AND company did SOLD
13. Products show "Sold" status badge (gray)
14. "Add Trace" button hidden (product no longer in custody)
15. Empty state: "No products sold yet"

### Product History Tab
16. Shows all products from `GET /api/products?history=me`
17. Products include status badge (IN_STOCK or SOLD)
18. Products include current owner info
19. "Add Trace" button shown only for products in custody
20. Empty state: "No product history yet"

### Both Tabs
21. Product cards show Timeline expand/collapse button
22. Timeline works for products in all tabs
23. Loading and error states handled per tab

### Technical Specifications

**Tab Implementation:**

```typescript
// src/pages/retailer/dashboard.tsx
import {
  Tabs,
  TabList,
  TabPanels,
  Tab,
  TabPanel,
  Badge,
} from '@chakra-ui/react';

// State for all three lists
const [inStockProducts, setInStockProducts] = useState<Product[]>([]);
const [soldProducts, setSoldProducts] = useState<Product[]>([]);
const [historyProducts, setHistoryProducts] = useState<Product[]>([]);
const [activeTab, setActiveTab] = useState(0);

// Fetch and filter logic
const fetchProducts = async () => {
  // Fetch products in custody
  const custodyRes = await fetch('/api/products?owner=me');
  const custodyData = await custodyRes.json();

  // Filter: In Stock = owner=me AND status !== SOLD
  const inStock = custodyData.products.filter(p => p.status !== 'SOLD');
  setInStockProducts(inStock);
};

const fetchSoldProducts = async () => {
  // Fetch history and filter for products I sold
  const historyRes = await fetch('/api/products?history=me');
  const historyData = await historyRes.json();

  // Filter: Products where status = SOLD
  // (The SOLD action would have been by this company since they owned it)
  const sold = historyData.products.filter(p => p.status === 'SOLD');
  setSoldProducts(sold);
};

const fetchHistoryProducts = async () => {
  const res = await fetch('/api/products?history=me');
  const data = await res.json();
  setHistoryProducts(data.products);
};

// In JSX:
<Tabs index={activeTab} onChange={setActiveTab} colorScheme="green">
  <TabList>
    <Tab>
      In Stock
      <Badge ml={2} colorScheme="green" borderRadius="full">
        {inStockProducts.length}
      </Badge>
    </Tab>
    <Tab>
      Sold
      <Badge ml={2} colorScheme="gray" borderRadius="full">
        {soldProducts.length}
      </Badge>
    </Tab>
    <Tab>
      Product History
      <Badge ml={2} colorScheme="blue" borderRadius="full">
        {historyProducts.length}
      </Badge>
    </Tab>
  </TabList>

  <TabPanels>
    <TabPanel px={0}>
      <ProductGrid
        products={inStockProducts}
        showAddTrace={true}
        emptyMessage="No products in stock yet"
      />
    </TabPanel>
    <TabPanel px={0}>
      <ProductGrid
        products={soldProducts}
        showAddTrace={false}
        emptyMessage="No products sold yet"
      />
    </TabPanel>
    <TabPanel px={0}>
      <ProductGrid
        products={historyProducts}
        showAddTrace={(p) => p.currentOwner?.name === companyName}
        emptyMessage="No product history yet"
      />
    </TabPanel>
  </TabPanels>
</Tabs>
```

**Sold Products Logic:**

Since Story 7.11 sets `currentOwnerId = null` when SOLD, and we're filtering by `status === 'SOLD'` from the history endpoint, this should correctly capture products where:
1. The retailer had the product in custody
2. The retailer performed the SOLD action
3. The product is now marked as sold (status = SOLD)

|-----|-------|--------|----------------|
