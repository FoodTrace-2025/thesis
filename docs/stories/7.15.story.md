# Story 7.15: Retailer Dashboard Tabs

## Status

**Complete** (2025-12-05)

## Story

**As a** retailer,
**I want** to switch between "In Stock" and "Product History" views,
**so that** I can manage my current inventory and see my complete handling history including sold items.

## Background

Currently, the retailer dashboard only shows "Products in Custody" (`owner=me`). After a product is sold (SOLD action), it disappears from the list, which can be confusing.

This story adds tabs (same pattern as Distributor Dashboard - Story 7.14):
- **In Stock (N)**: Products I currently own
- **Product History (M)**: All products I've ever touched (including sold items with status badges)

### Design Decision (Research-Based)

Per [NN/g - Tabs Used Right](https://www.nngroup.com/articles/tabs-used-right/): "Limit the tab count - too many tabs create usability challenges."

Originally planned 3 tabs (In Stock, Sold, Product History), but simplified to 2 tabs because:
1. Story 7.12 already adds status badges (IN_STOCK, SOLD) visible on every product card
2. Product History tab shows sold items with their SOLD badge - no need for separate tab
3. Consistency with Distributor Dashboard (Story 7.14)
4. Reduces cognitive load per [inventory UX patterns](https://www.uxpin.com/studio/blog/inventory-app-design/)

## Acceptance Criteria

### Tab Navigation
1. Two tabs displayed: "In Stock" and "Product History"
2. Each tab shows count badge with number of items
3. "In Stock" tab selected by default on page load
4. Clicking tab switches content without full page reload
5. Tab styling follows Chakra UI Tabs component patterns (variant="enclosed")

### In Stock Tab
6. Shows products where `currentOwnerId = myCompany` (owner=me)
7. Products include status badge (from Story 7.12)
8. "Add Trace" button visible for products in custody
9. Empty state: "No products in stock yet"

### Product History Tab
10. Shows products from `GET /api/products?history=me` (Story 7.13)
11. Products include status badge (IN_STOCK or SOLD)
12. Products include current owner info ("Sold to Consumer" for sold items)
13. "Add Trace" button hidden for products not in custody
14. Empty state: "No product history yet"

### Both Tabs
15. Product cards show Timeline expand/collapse button
16. Timeline works for products in either tab
17. Loading and error states handled per tab

### Technical Specifications

**Implementation Pattern:** Follow Story 7.14 (Distributor Dashboard) exactly - same 2-tab structure.

```typescript
// src/pages/retailer/dashboard.tsx
import {
  Tabs,
  TabList,
  TabPanels,
  Tab,
  TabPanel,
  Badge,
} from '@chakra-ui/react';

// State for both lists
const [inStockProducts, setInStockProducts] = useState<Product[]>([]);
const [inStockLoading, setInStockLoading] = useState(true);
const [inStockError, setInStockError] = useState<string | null>(null);

const [historyProducts, setHistoryProducts] = useState<Product[]>([]);
const [historyLoading, setHistoryLoading] = useState(false);
const [historyError, setHistoryError] = useState<string | null>(null);
const [historyLoaded, setHistoryLoaded] = useState(false); // Lazy load flag
const [activeTab, setActiveTab] = useState(0);

// Fetch in-stock products (owner=me)
const fetchInStockProducts = async () => {
  setInStockLoading(true);
  setInStockError(null);
  try {
    const response = await fetch('/api/products?owner=me');
    const data = await response.json();
    if (!response.ok) {
      setInStockError(data.error || 'Failed to fetch products');
      return;
    }
    setInStockProducts(data.products);
  } catch {
    setInStockError('Network error. Please try again.');
  } finally {
    setInStockLoading(false);
  }
};

// Fetch history products (history=me) - lazy loaded on first tab switch
const fetchHistoryProducts = async () => {
  setHistoryLoading(true);
  setHistoryError(null);
  try {
    const response = await fetch('/api/products?history=me');
    const data = await response.json();
    if (!response.ok) {
      setHistoryError(data.error || 'Failed to fetch history');
      return;
    }
    setHistoryProducts(data.products);
    setHistoryLoaded(true);
  } catch {
    setHistoryError('Network error. Please try again.');
  } finally {
    setHistoryLoading(false);
  }
};

// Lazy load history on first tab switch (using boolean flag, not length)
const handleTabChange = (index: number) => {
  setActiveTab(index);
  if (index === 1 && !historyLoaded) {
    fetchHistoryProducts();
  }
};

// After trace success, refetch both lists
const handleTraceSuccess = () => {
  onClose();
  setSelectedProductId(null);
  fetchInStockProducts();
  if (historyLoaded) {
    fetchHistoryProducts();
  }
  toast({ /* success message */ });
};

// In JSX:
<Tabs index={activeTab} onChange={handleTabChange} colorScheme="green" variant="enclosed">
  <TabList>
    <Tab>
      In Stock
      <Badge ml={2} colorScheme="green" borderRadius="full">
        {inStockProducts.length}
      </Badge>
    </Tab>
    <Tab>
      Product History
      <Badge ml={2} colorScheme="gray" borderRadius="full">
        {historyProducts.length}
      </Badge>
    </Tab>
  </TabList>

  <TabPanels>
    <TabPanel px={0}>
      {/* In Stock: Loading, Error, Empty, Grid states */}
    </TabPanel>
    <TabPanel px={0}>
      {/* Product History: Loading, Error, Empty, Grid states */}
    </TabPanel>
  </TabPanels>
</Tabs>
```

**Key Implementation Notes:**

1. **No redundant filter**: Unlike original story, do NOT filter `status !== 'SOLD'` on In Stock tab. The `owner=me` query already excludes sold products because Story 7.11 sets `currentOwnerId = null` on SOLD action.

2. **Lazy loading with boolean flag**: Use `historyLoaded` boolean, not `historyProducts.length === 0`, to prevent unnecessary refetches.

3. **Add Trace visibility**: Use `product.currentOwner?.name === companyName` check (same as Story 7.14).

### Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| Duplicate fetches on tab switch | Use `historyLoaded` boolean flag |
| Inconsistent state after trace add | Refetch both lists after successful trace |
| Tab counts stale | Update counts when products are added/removed |
