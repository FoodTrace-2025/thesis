# Story 2.10: Add Company Admin Form

## Status

**Complete** (2025-12-02)

## Story

**As a** platform administrator,
**I want** to create company admin users from the admin dashboard,
**so that** I can complete the B2B onboarding flow without using curl/Postman.

## Acceptance Criteria

1. "Add Admin" button visible in ACTIONS column for APPROVED companies only
2. Button opens modal with form fields: Company (read-only), Name, Email
3. Email hint shows required domain (e.g., "Must end with @company.com")
4. Form validates required fields before submission
5. Submit calls POST /api/admin/users with hard-coded password "admin123"
6. Success: closes modal, shows success toast with default password info
7. Error: shows error message in modal (e.g., email domain mismatch, duplicate email)
8. Cancel button closes modal without action
9. Default password documented in .env.local as `DEFAULT_COMPANY_ADMIN_PASSWORD=admin123`

### API Reference

**POST /api/admin/users** (Story 2.6)

Request:
```json
{
  "name": "Company Admin",
  "email": "admin@company.com",
  "password": "admin123",
  "companyId": "company-id-here"
}
```

Success Response (201):
```json
{
  "success": true,
  "user": {
    "id": "...",
    "email": "admin@company.com",
    "name": "Company Admin",
    "role": "COMPANY_ADMIN",
    "companyId": "..."
  }
}
```

Error Responses:
- 400: Email domain mismatch (`"Email must match company domain: company.com"`)
- 400: Company not approved
- 404: Company not found
- 409: Duplicate email (`"User with this email already exists"`)

### Error Handling

| Error | User Feedback |
|-------|---------------|
| Empty required field | Disable submit button |
| Email domain mismatch (400) | Show error in modal |
| Duplicate email (409) | Show error in modal |
| Company not found (404) | Show error in modal |
| API failure | Show error toast |

### Key Design Decisions
1. **Teal button color** - Distinguishes "Add Admin" from "Approve" (green) and "Reject" (red)
2. **Read-only company field** - Company pre-selected, cannot be changed
3. **Email domain hint** - Shows "Must end with @{domain}" below email field
4. **Hard-coded password** - "admin123" for POC simplicity (documented in .env files)
5. **Success toast content** - Explicitly shows default password so admin can communicate it
