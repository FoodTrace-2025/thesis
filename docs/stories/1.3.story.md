### Reference Information

**From Epic 1 (docs/prd/epic-1-project-setup.md):**

- Etherscan API key is required for contract verification
- Verification publishes smart contract source code publicly
- This enables transparency and trust in deployed contracts
- Required for Hardhat verify plugin (`@nomicfoundation/hardhat-verify`)

**Required Environment Variable Format:**

```bash
# Contract Verification (Etherscan)
ETHERSCAN_API_KEY="YOUR_35_CHARACTER_API_KEY"
```

**Why Etherscan Verification?**

- **Transparency:** Users can read verified contract source code
- **Trust:** Proves deployed bytecode matches source code
- **Debugging:** Etherscan shows decoded function calls and events
- **Academic:** Demonstrates professional blockchain development practices
- **Free:** No cost for API key or verification
