### Technical Specifications

**create-next-app Options:**

```bash
npx create-next-app@14.2.15 . --typescript --use-npm
# When prompted:
# - Use ESLint? Yes
# - Use Tailwind CSS? No (using Chakra UI)
# - Use `src/` directory? Yes
# - Use App Router? No (Pages Router)
# - Customize import alias? Yes (@/*)
```

**Expected tsconfig.json Settings:**

```json
{
  "compilerOptions": {
    "strict": true,
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

**Expected Folder Structure After:**

```
thesis/
├── src/
│   ├── pages/
│   │   ├── _app.tsx
│   │   ├── _document.tsx
│   │   └── index.tsx
│   ├── components/
│   ├── lib/
│   └── styles/
│       └── globals.css
├── public/
├── package.json
├── tsconfig.json
├── next.config.js
└── (existing files: docs/, .env.local, etc.)
```

### Risks & Mitigations

| Risk                             | Mitigation                                        |
| -------------------------------- | ------------------------------------------------- |
| Existing .gitignore overwritten  | Backup before running create-next-app             |
| Wrong Next.js version            | Pin to 14.2.15 explicitly                         |
| App Router selected by accident  | Double-check Pages Router selection               |
| Conflicts with existing files    | Review merge carefully, preserve docs/, .env.local |
