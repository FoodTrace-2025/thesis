# Story 13.4: Smoke Testing

## Status

**TODO** - Ready for development (after Story 13.3)

## Story

**As a** deployment operator,
**I want** to verify all core features work on production,
**so that** the thesis demo is reliable and all functionality is accessible.

## Acceptance Criteria

### Authentication Testing
1. Platform admin can login with test credentials
2. Login redirects to appropriate dashboard
3. Session persists across page refreshes
4. Logout works correctly

### Company & User Management Testing
5. Company admin can login (if test company exists)
6. Company dashboard loads without errors
7. User list displays correctly

### Product Registration Testing
8. Producer can create a new product (Epic 5)
9. Product appears in product list
10. QR code generates and displays
11. Product details page loads

### Supply Chain Testing
12. Transfer workflow works (send to next party)
13. Trace records appear in timeline
14. Recipient can view incoming shipment

### Consumer Query Testing (After Epic 9)
15. `/trace` page loads (consumer landing)
16. Manual product lookup works
17. Product detail page shows journey timeline
18. QR scanner works on mobile (HTTPS required)

### Error Handling Testing
19. 404 page renders for invalid routes
20. Error boundary catches runtime errors
21. No sensitive data in error messages

### Mobile Testing
22. All pages responsive on mobile (360px width)
23. Touch targets minimum 44px
24. QR scanner works on mobile browser (iPhone Safari, Android Chrome)
