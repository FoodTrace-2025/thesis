# Story 9.4: Share Button and Responsive Polish

## Status

**DONE** - Implemented in PR #4, verified 2025-12-14

## Story

**As a** consumer,
**I want** to share a product's traceability page with friends,
**so that** I can show them where my food comes from and encourage them to check their own products.

## Acceptance Criteria

### Share Button
1. Share button displayed on product detail page header
2. Button has share icon (link/share icon from Chakra)
3. Clicking button copies current URL to clipboard
4. Toast notification confirms "Link copied to clipboard"
5. Button is accessible (proper aria-label)

### Responsive Polish
6. Page renders correctly at 360px width (iPhone SE)
7. Page renders correctly at 768px width (tablet)
8. Page renders correctly at 1280px width (desktop)
9. Product header stacks vertically on mobile (<768px)
10. Timeline events are readable on all screen sizes
11. Touch targets are at least 44px on mobile

### Consumer UX Polish
12. Page has proper meta tags for social sharing (og:title, og:description)
13. Loading states have proper feedback (spinner with text)
14. All text is readable without zooming (min 16px font)
15. Color contrast meets WCAG AA standards (already handled by theme)

### Technical Specifications

**Share Button Implementation:**

```typescript
// Add to src/pages/trace/[id].tsx
import Head from 'next/head';
import { LinkIcon } from '@chakra-ui/icons';

// In component:
const handleShare = async () => {
  try {
    await navigator.clipboard.writeText(window.location.href);
    toast({
      title: 'Link copied!',
      description: 'Share this link with friends to show them the product journey.',
      status: 'success',
      duration: 3000,
      isClosable: true,
    });
  } catch (err) {
    toast({
      title: 'Failed to copy',
      description: 'Please copy the URL from your browser address bar.',
      status: 'error',
      duration: 3000,
      isClosable: true,
    });
  }
};

// In JSX - Product Header:
<HStack justify="space-between" w="full">
  <Heading size="lg" color="brand.dark">
    {product.name}
  </Heading>
  <HStack>
    <Badge colorScheme="green" fontSize="sm">
      Product #{product.blockchainId}
    </Badge>
    <IconButton
      aria-label="Share product link"
      icon={<LinkIcon />}
      variant="ghost"
      onClick={handleShare}
      size="sm"
    />
  </HStack>
</HStack>
```
