# Story 7.19: Quarantined Products Tab

## Status

**Complete** (Implemented and tested 2025-12-28, revised to My Products tab approach)

## Story

**As a** distributor or retailer,
**I want** to see quarantined products in a separate tab within My Products,
**so that** I can easily identify and manage products that failed quality inspection.

## Background

Story 7.18 implements the core QUALITY_FAIL action and `isQuarantined` flag. This story adds the UI to display quarantined products.

Per [SG Systems Global best practices](https://sgsystemsglobal.com/guides/inventory-quarantine-system/): "If quarantine doesn't stop a pick, it isn't quarantine—it's décor." The separate tab provides visual separation from sellable inventory.

**Design Decision:** Initially implemented as a dashboard section (product cards). After UX review, moved to My Products as a third tab because:
- Dashboard = Summary view (KPIs, trends, counts only)
- My Products = Operational view (tables with search, filter, actions)
- Product lists belong in operational view, not summary view
- Table format scales better for multiple quarantined products
- Consistent with existing In Custody / Product History tab pattern

## Acceptance Criteria

### Distributor My Products
1. "Quarantined" tab displayed as third tab (after In Custody, Product History)
2. Tab fetches data using `GET /api/products?quarantined=me` (from Story 7.18)
3. Tab uses red badge styling to indicate warning
4. Table shows same columns as other tabs (Blockchain ID, Product, Origin, Owner, Status)
5. Lazy-loaded on tab click (same pattern as Product History)

### Retailer My Products
6. Same functionality as distributor
7. "Quarantined" tab as third tab

### Edge Cases
8. Loading state shows spinner
9. Error state shows error message
10. Badge count updates when data refreshes

### Technical Specifications

**My Products Tab (Pattern from existing tabs):**

```typescript
// In distributor/products.tsx and retailer/products.tsx

// Add state
const [quarantineRows, setQuarantineRows] = useState<BatchTableRow[]>([]);
const [quarantineLoading, setQuarantineLoading] = useState(false);
const [quarantineError, setQuarantineError] = useState<string | null>(null);
const [quarantineLoaded, setQuarantineLoaded] = useState(false);

// Update filteredRows to include quarantine tab
const filteredRows = useMemo(() => {
  const rows = activeTab === 0 ? custodyRows : activeTab === 1 ? historyRows : quarantineRows;
  // ... existing filter logic
}, [activeTab, custodyRows, historyRows, quarantineRows, query, status]);

// Fetch function
const fetchQuarantine = useCallback(async () => {
  setQuarantineLoading(true);
  setQuarantineError(null);
  try {
    const res = await fetch("/api/products?quarantined=me");
    const data = await res.json();
    if (!res.ok) {
      setQuarantineError(data.error || "Failed to fetch quarantined products");
      return;
    }
    const mapped: BatchTableRow[] = (data.products as ApiProduct[]).map(/* ... */);
    setQuarantineRows(mapped);
    setQuarantineLoaded(true);
  } catch {
    setQuarantineError("Network error. Please try again.");
  } finally {
    setQuarantineLoading(false);
  }
}, []);

// Lazy-load on tab change
<Tabs
  onChange={(index) => {
    setActiveTab(index);
    if (index === 2 && !quarantineLoaded) {
      fetchQuarantine();
    }
  }}
>
  <TabList>
    <Tab>In Custody <Badge>...</Badge></Tab>
    <Tab>Product History <Badge>...</Badge></Tab>
    <Tab>Quarantined <Badge colorScheme="red">{quarantineRows.length}</Badge></Tab>
  </TabList>
  <TabPanels>
    {/* ... existing panels ... */}
    <TabPanel>
      <Filters ... />
      <TableState isLoading={quarantineLoading} error={quarantineError} rows={filteredRows} />
    </TabPanel>
  </TabPanels>
</Tabs>
```

### Design Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Location | My Products tab (not Dashboard) | Dashboard = summary, My Products = operations |
| Styling | Red badge on tab | Visual warning, consistent with error theme |
| Loading | Lazy-load on tab click | Same pattern as Product History tab |
| Table format | Reuse BatchTable | Consistent with other tabs, scalable |
| Disposition actions | Not included | POC scope - display only (Future Work) |

### Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| Too many quarantined products | Table format with search/filter handles scale |
| User might miss quarantined | Red badge on tab provides visibility |
