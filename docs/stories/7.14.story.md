# Story 7.14: Distributor Dashboard Tabs

## Status

**Complete** (2025-12-05)

## Story

**As a** distributor,
**I want** to switch between "In Custody" and "Product History" views,
**so that** I can see both my current inventory and all products I've ever handled.

## Background

Currently, the distributor dashboard only shows "Products in Custody" (`owner=me`). After ownership transfers to a retailer, products disappear from the list, which can be confusing.

This story adds tabs:
- **In Custody (N)**: Products I currently own (existing behavior)
- **Product History (M)**: All products I've ever touched (new)

## Acceptance Criteria

### Tab Navigation
1. Two tabs displayed: "In Custody" and "Product History"
2. Each tab shows count badge with number of items
3. "In Custody" tab selected by default on page load
4. Clicking tab switches content without full page reload
5. Tab styling follows Chakra UI Tabs component patterns

### In Custody Tab
6. Shows products where `currentOwnerId = myCompany` (existing)
7. Products include status badge (from Story 7.12)
8. "Add Trace" button visible for products in custody
9. Empty state: "No products in custody yet"

### Product History Tab
10. Shows products from `GET /api/products?history=me` (Story 7.13)
11. Products include status badge (IN_STOCK or SOLD)
12. Products include current owner info
13. "Add Trace" button hidden for products not in custody
14. Empty state: "No product history yet"

### Both Tabs
15. Product cards show Timeline expand/collapse button
16. Timeline works for products in either tab
17. Loading and error states handled per tab

### Technical Specifications

**Tab Implementation:**

```typescript
// src/pages/distributor/dashboard.tsx
import {
  Tabs,
  TabList,
  TabPanels,
  Tab,
  TabPanel,
  Badge,
} from '@chakra-ui/react';

// State for both lists
const [custodyProducts, setCustodyProducts] = useState<Product[]>([]);
const [historyProducts, setHistoryProducts] = useState<Product[]>([]);
const [custodyLoading, setCustodyLoading] = useState(true);
const [historyLoading, setHistoryLoading] = useState(false);
const [activeTab, setActiveTab] = useState(0);

// Fetch functions
const fetchCustodyProducts = async () => {
  setCustodyLoading(true);
  const res = await fetch('/api/products?owner=me');
  const data = await res.json();
  setCustodyProducts(data.products);
  setCustodyLoading(false);
};

const fetchHistoryProducts = async () => {
  setHistoryLoading(true);
  const res = await fetch('/api/products?history=me');
  const data = await res.json();
  setHistoryProducts(data.products);
  setHistoryLoading(false);
};

// Fetch history on first tab switch (lazy loading)
const handleTabChange = (index: number) => {
  setActiveTab(index);
  if (index === 1 && historyProducts.length === 0) {
    fetchHistoryProducts();
  }
};

// In JSX:
<Tabs index={activeTab} onChange={handleTabChange} colorScheme="green">
  <TabList>
    <Tab>
      In Custody
      <Badge ml={2} colorScheme="green" borderRadius="full">
        {custodyProducts.length}
      </Badge>
    </Tab>
    <Tab>
      Product History
      <Badge ml={2} colorScheme="gray" borderRadius="full">
        {historyProducts.length}
      </Badge>
    </Tab>
  </TabList>

  <TabPanels>
    <TabPanel px={0}>
      {/* Existing product grid for custody */}
      <ProductGrid
        products={custodyProducts}
        isLoading={custodyLoading}
        showAddTrace={true}
        emptyMessage="No products in custody yet"
      />
    </TabPanel>
    <TabPanel px={0}>
      {/* New product grid for history */}
      <ProductGrid
        products={historyProducts}
        isLoading={historyLoading}
        showAddTrace={false}
        emptyMessage="No product history yet"
      />
    </TabPanel>
  </TabPanels>
</Tabs>
```

### UX Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Tab count badges | Always visible | Users see quantity at glance without clicking |
| History tab lazy load | Load on first click | Reduces initial page load time |
| Add Trace visibility | Only for owned products | Prevents confusion about what you can modify |
| Tab default | In Custody | Most common use case is checking current inventory |

### Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| Duplicate fetches on tab switch | Cache results, only fetch if empty |
| Inconsistent state after trace add | Refetch both lists after successful trace |
| Tab counts stale | Update counts when products are added/removed |
