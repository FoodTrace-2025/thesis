### Technical Specifications

**Required npm packages:**

```bash
npm install --save-dev hardhat @nomicfoundation/hardhat-toolbox
npm install @openzeppelin/contracts
```

**hardhat.config.ts structure:**

```typescript
import { HardhatUserConfig } from "hardhat/config";
import "@nomicfoundation/hardhat-toolbox";

const config: HardhatUserConfig = {
  solidity: "0.8.20",
  networks: {
    hardhat: {
      chainId: 31337,
    },
    sepolia: {
      url: process.env.SEPOLIA_RPC_URL || "",
      accounts: process.env.PRIVATE_KEY ? [process.env.PRIVATE_KEY] : [],
    },
  },
  etherscan: {
    apiKey: process.env.ETHERSCAN_API_KEY,
  },
};

export default config;
```

### Risks & Mitigations

| Risk                          | Mitigation                                      |
| ----------------------------- | ----------------------------------------------- |
| TypeScript config conflicts   | Use hardhat-toolbox (includes TS support)       |
| Wrong Solidity version        | Pin to 0.8.20 explicitly                        |
| Missing env vars              | Check .env.local has all required values        |
| OpenZeppelin version mismatch | Use 5.x for Solidity 0.8.20 compatibility       |

npx hardhat --network sepolia accounts
