# Story 7.7: Distributor Dashboard - Trace Features

## Status

**Done**

## Story

**As a** distributor,
**I want** to add trace records and view trace history for products in my custody,
**so that** I can document the product journey and maintain supply chain transparency.

## Acceptance Criteria

### Add Trace Record Feature
1. Each product card has an "Add Trace Record" button
2. Clicking button opens modal with TraceRecordForm component
3. TraceRecordForm receives productId and userRole="DISTRIBUTOR" as props
4. Form shows only DISTRIBUTOR actions: RECEIVED, QUALITY_CHECK, SHIPPED
5. Successful submission closes modal and shows success toast
6. Products list refreshes after successful trace record submission

### View Timeline Feature
7. Each product card has a "View Timeline" button
8. Clicking button expands/shows TraceTimeline component inline below the card
9. TraceTimeline receives productId as prop
10. Timeline collapses when button clicked again (toggle behavior)
11. Only one timeline can be expanded at a time

### Receive Product Feature
12. Dashboard has "Receive New Product" section
13. Section contains blockchain ID input field with "Look Up" button
14. Looking up valid blockchain ID displays product info + TraceRecordForm
15. Looking up invalid blockchain ID shows error message
16. After successfully adding RECEIVED trace record, product appears in "Products in Custody" list

### Technical Specifications

**Modal for Trace Record Form:**

```typescript
import { Modal, ModalOverlay, ModalContent, ModalHeader, ModalCloseButton, ModalBody, useDisclosure } from '@chakra-ui/react';
import { TraceRecordForm } from '@/components/trace';

const { isOpen, onOpen, onClose } = useDisclosure();
const [selectedProductId, setSelectedProductId] = useState<string | null>(null);

const handleAddTrace = (productId: string) => {
  setSelectedProductId(productId);
  onOpen();
};

const handleTraceSuccess = () => {
  onClose();
  setSelectedProductId(null);
  fetchProducts(); // Refetch to update list
  toast({ title: 'Trace record added', status: 'success' });
};

// In JSX:
<Modal isOpen={isOpen} onClose={onClose} size="lg">
  <ModalOverlay />
  <ModalContent>
    <ModalHeader>Add Trace Record</ModalHeader>
    <ModalCloseButton />
    <ModalBody pb={6}>
      {selectedProductId && (
        <TraceRecordForm
          productId={selectedProductId}
          userRole="DISTRIBUTOR"
          onSuccess={handleTraceSuccess}
        />
      )}
    </ModalBody>
  </ModalContent>
</Modal>
```

**Timeline Expand/Collapse:**

```typescript
const [expandedProductId, setExpandedProductId] = useState<string | null>(null);

const toggleTimeline = (productId: string) => {
  setExpandedProductId(prev => prev === productId ? null : productId);
};

// In product card:
<Button size="sm" onClick={() => toggleTimeline(product.id)}>
  {expandedProductId === product.id ? 'Hide Timeline' : 'View Timeline'}
</Button>

{expandedProductId === product.id && (
  <Box mt={4} pl={4} borderLeftWidth="2px" borderColor="brand.accent">
    <TraceTimeline productId={product.id} />
  </Box>
)}
```

**Receive Product Lookup (using blockchainId):**

```typescript
const [blockchainId, setBlockchainId] = useState('');
const [lookupProduct, setLookupProduct] = useState<Product | null>(null);
const [lookupError, setLookupError] = useState('');
const [isLookingUp, setIsLookingUp] = useState(false);

const handleLookup = async () => {
  if (!blockchainId.trim()) return;
  setIsLookingUp(true);
  setLookupError('');
  setLookupProduct(null);

  try {
    // Lookup by blockchainId (user-friendly integer, matches QR codes)
    const response = await fetch(`/api/products/${blockchainId}`);
    const data = await response.json();
    if (!response.ok) {
      setLookupError(data.error || 'Product not found');
      return;
    }
    setLookupProduct(data.product);
  } catch {
    setLookupError('Network error. Please try again.');
  } finally {
    setIsLookingUp(false);
  }
};

const handleReceiveSuccess = () => {
  setLookupProduct(null);
  setBlockchainId('');
  fetchProducts(); // Refetch to show new product in custody
};
```
