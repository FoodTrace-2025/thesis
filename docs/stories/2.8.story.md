# Story 2.8: Platform Admin Dashboard UI

## Status

**Draft** (Ready for implementation)

## Story

**As a** platform administrator,
**I want** a dashboard to view and manage companies,
**so that** I can approve or reject company registrations efficiently.

## Acceptance Criteria

1. Admin dashboard page accessible at `/admin` route
2. Only PLATFORM_ADMIN role can access (redirect others to `/dashboard` or `/login`)
3. Company list table displays: Name, Email, Domain, Type, Status, Created Date
4. Status filter dropdown filters by ALL, PENDING, APPROVED, REJECTED
5. PENDING companies show "Approve" and "Reject" action buttons
6. "Approve" button opens confirmation modal before calling API
7. "Reject" button opens modal with required reason input before calling API
8. Status badges: PENDING (yellow), APPROVED (green), REJECTED (red)
9. APPROVED companies show truncated wallet address
10. Toast notification on successful approve/reject
11. Error toast on API failure
12. Empty state message when no companies match filter

### Task 0: Stub Dashboard Page

```typescript
// src/pages/dashboard.tsx (stub - full implementation in Epic 12)
import { getServerSession } from 'next-auth';
import { authOptions } from '@/pages/api/auth/[...nextauth]';
import type { GetServerSidePropsContext } from 'next';
import { Box, Heading, Text } from '@chakra-ui/react';
import { Layout } from '@/components/layout';

export async function getServerSideProps(context: GetServerSidePropsContext) {
  const session = await getServerSession(context.req, context.res, authOptions);

  if (!session) {
    return { redirect: { destination: '/login', permanent: false } };
  }

  // PLATFORM_ADMIN should use /admin, not /dashboard
  if (session.user.role === 'PLATFORM_ADMIN') {
    return { redirect: { destination: '/admin', permanent: false } };
  }

  return { props: {} };
}

export default function Dashboard() {
  return (
    <Layout>
      <Box textAlign="center" py={10}>
        <Heading mb={4}>Dashboard</Heading>
        <Text color="gray.600">Coming soon in Epic 12</Text>
      </Box>
    </Layout>
  );
}
```

### Auth Pattern (getServerSideProps)

```typescript
// src/pages/admin/index.tsx
import { getServerSession } from 'next-auth';
import { authOptions } from '@/pages/api/auth/[...nextauth]';
import type { GetServerSidePropsContext } from 'next';

export async function getServerSideProps(context: GetServerSidePropsContext) {
  const session = await getServerSession(context.req, context.res, authOptions);

  if (!session) {
    return { redirect: { destination: '/login', permanent: false } };
  }

  if (session.user.role !== 'PLATFORM_ADMIN') {
    return { redirect: { destination: '/dashboard', permanent: false } };
  }

  return { props: {} };
}
```

### API Calls

```typescript
// Fetch companies with optional status filter
const fetchCompanies = async (status?: string) => {
  const url = status && status !== 'ALL'
    ? `/api/admin/companies?status=${status}`
    : '/api/admin/companies';
  const res = await fetch(url);
  return res.json();
};

// Approve company
const approveCompany = async (companyId: string) => {
  const res = await fetch(`/api/admin/companies/${companyId}/approve`, {
    method: 'POST',
  });
  return res.json();
};

// Reject company
const rejectCompany = async (companyId: string, reason: string) => {
  const res = await fetch(`/api/admin/companies/${companyId}/reject`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ reason }),
  });
  return res.json();
};
```

### Error Handling

| Error | User Feedback |
|-------|---------------|
| Not authenticated | Redirect to `/login` |
| Not PLATFORM_ADMIN | Redirect to `/dashboard` |
| API fetch fails | Error toast: "Failed to load companies" |
| Approve API fails | Error toast: "Failed to approve company" |
| Reject API fails | Error toast: "Failed to reject company" |
| Empty reason on reject | Disable submit button, show validation message |

### Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| Accidental approval | Confirmation modal before approve action |
| Accidental rejection | Confirmation modal with required reason |
| Session expires during action | API returns 401, redirect to login |
| Network failure during action | Error toast with retry option |
