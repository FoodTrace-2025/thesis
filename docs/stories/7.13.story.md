# Story 7.13: Product History API

## Status

**Draft** (2025-12-05)

## Story

**As a** distributor or retailer,
**I want** to query all products I have ever added trace records to,
**so that** I can view my complete product handling history even after ownership has transferred.

## Background

Currently, the `/api/products` endpoint supports:
- `owner=me`: Products currently owned by my company
- `company=me`: Products registered by my company (for producers)

This story adds:
- `history=me`: Products where my company has added ANY trace record

This enables the "Product History" tab showing all products a company has ever touched.

## Acceptance Criteria

### API Enhancement
1. GET /api/products accepts `history=me` query parameter
2. `history=me` returns products where company has any trace record
3. Products are returned in descending order by most recent trace action
4. Response includes same fields as existing endpoint (id, name, status, currentOwner, etc.)
5. Pagination supported (limit, offset parameters)

### Query Logic
6. Query joins Product with TraceRecord where traceRecord.companyId = session.companyId
7. Duplicate products removed (DISTINCT on product.id)
8. Works correctly for all roles (PRODUCER, DISTRIBUTOR, RETAILER)

### Authentication
9. `history=me` requires authentication (401 if not logged in)
10. Returns only products related to authenticated user's company

**History Query Implementation:**

```typescript
// Add after owner/company handling
if (history === 'me') {
  const session = await getServerSession(req, res, authOptions);
  if (!session?.user?.companyId) {
    return res.status(401).json({
      error: 'Authentication required',
      code: 'UNAUTHORIZED',
    });
  }

  // Find all products where company has trace records
  const productIdsWithTraces = await prisma.traceRecord.findMany({
    where: { companyId: session.user.companyId },
    select: { productId: true },
    distinct: ['productId'],
    orderBy: { createdAt: 'desc' },
  });

  const productIds = productIdsWithTraces.map(t => t.productId);

  const [products, total] = await Promise.all([
    prisma.product.findMany({
      where: { id: { in: productIds } },
      include: { currentOwner: { select: { name: true } } },
      take: limit,
      skip: offset,
    }),
    prisma.product.count({ where: { id: { in: productIds } } }),
  ]);

  // Add status field (same logic as Story 7.12)
  const productsWithStatus = await Promise.all(
    products.map(async (product) => {
      const lastTrace = await prisma.traceRecord.findFirst({
        where: { productId: product.id },
        orderBy: { createdAt: 'desc' },
        select: { action: true },
      });
      return {
        ...formatProduct(product),
        status: lastTrace?.action === 'SOLD' ? 'SOLD' : 'IN_STOCK',
      };
    })
  );

  return res.status(200).json({
    success: true,
    products: productsWithStatus,
    total,
    limit,
    offset,
  });
}
```

**Alternative: Single Optimized Query:**

```typescript
// More efficient approach using raw query or Prisma's relationFilter
const products = await prisma.product.findMany({
  where: {
    traceRecords: {
      some: { companyId: session.user.companyId },
    },
  },
  include: {
    currentOwner: { select: { name: true } },
    traceRecords: {
      where: { companyId: session.user.companyId },
      orderBy: { createdAt: 'desc' },
      take: 1,
    },
  },
  take: limit,
  skip: offset,
});
```

### Query Parameter Combinations

| Query Params | Returns | Used By |
|--------------|---------|---------|
| `owner=me` | Products I currently own | Distributor/Retailer "In Custody" |
| `company=me` | Products I registered | Producer "My Registered Products" |
| `history=me` | Products I've touched | All roles "Product History" |
| (none) | All products | Public query |

### Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| N+1 queries for status | Batch query or accept for POC scale |
| Slow for companies with many trace records | Add index on traceRecord.companyId (already exists) |
| Conflicting params (owner=me&history=me) | Return 400 if multiple filters provided |
