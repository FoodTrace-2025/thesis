# Story 7.12: Product Status Badges and Labels

## Status

**Complete** (2025-12-05)

## Story

**As a** supply chain participant,
**I want** to see clear status badges and current owner information on product cards,
**so that** I can quickly understand the state of each product without expanding the timeline.

## Background

Current product cards show basic information but lack:
1. Visual status indicators (IN STOCK vs SOLD)
2. Clear display of which company currently holds the product
3. Consistent labeling across dashboards

This story adds visual badges and updates section labels for clarity.

## Acceptance Criteria

### Status Badge Component
1. StatusBadge component created with variants: IN_STOCK (green), SOLD (gray)
2. Badge displays appropriate text: "In Stock" or "Sold"
3. Badge uses Chakra UI Badge component with colorScheme

### Product Card Updates
4. All product cards show status badge (inferred from last trace action)
5. All product cards display "Current Owner: {company name}" or "Current Owner: Sold to Consumer"
6. Status badge positioned consistently (top-right or after product name)

### Dashboard Label Updates
7. Producer dashboard section renamed to "My Registered Products"
8. Distributor dashboard section remains "Products in Custody"
9. Retailer dashboard section remains "Products in Custody"
10. Empty state messages updated to match new labels

### API Enhancement
11. GET /api/products returns `status` field (IN_STOCK or SOLD)
12. Status inferred from last trace action (SOLD = SOLD, anything else = IN_STOCK)
13. Products with no trace records default to IN_STOCK

### Technical Specifications

**Products API Enhancement:**

```typescript
// In src/pages/api/products/index.ts
// After fetching products, get last trace action for each

const productsWithStatus = await Promise.all(
  products.map(async (product) => {
    const lastTrace = await prisma.traceRecord.findFirst({
      where: { productId: product.id },
      orderBy: { createdAt: 'desc' },
      select: { action: true },
    });

    return {
      ...product,
      status: lastTrace?.action === 'SOLD' ? 'SOLD' : 'IN_STOCK',
    };
  })
);
```

**StatusBadge Component:**

```typescript
// src/components/product/StatusBadge.tsx
import { Badge } from '@chakra-ui/react';

type ProductStatus = 'IN_STOCK' | 'SOLD';

interface StatusBadgeProps {
  status: ProductStatus;
}

const STATUS_CONFIG = {
  IN_STOCK: { label: 'In Stock', colorScheme: 'green' },
  SOLD: { label: 'Sold', colorScheme: 'gray' },
};

export function StatusBadge({ status }: StatusBadgeProps) {
  const config = STATUS_CONFIG[status];
  return (
    <Badge colorScheme={config.colorScheme} fontSize="xs">
      {config.label}
    </Badge>
  );
}
```

**Product Card Update:**
