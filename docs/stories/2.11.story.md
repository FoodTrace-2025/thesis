# Story 2.11: Login/Logout Header Buttons

## Status

**DONE**

## Story

**As a** user (platform admin, company admin, or company user),
**I want** to see login/logout buttons in the header,
**so that** I can easily authenticate or end my session from any page.

## Acceptance Criteria

1. Layout header shows "Login" button when user is NOT authenticated
2. Layout header shows "{Name} • Logout" when user IS authenticated
3. "Login" button links to `/login` page
4. "Logout" button calls NextAuth `signOut()` function
5. After logout, user is redirected to `/login` page
6. No confirmation modal (immediate logout on click)
7. Buttons appear on right side of header (logo on left, buttons on right)
8. Works on all pages using Layout: `/`, `/dashboard`, `/admin`
9. Loading state: Show "Login" button during initial session check (then switch to Logout if authenticated)

### Implementation Pattern

```typescript
// Layout.tsx
import { useSession, signOut } from 'next-auth/react';
import NextLink from 'next/link';
import { Button, HStack, Spacer } from '@chakra-ui/react';

export function Layout({ children }: LayoutProps) {
  const { data: session, status } = useSession();

  return (
    <Flex direction="column" minH="100vh" bg="brand.pageBg">
      <Box as="header" ...>
        <HStack maxW="1280px" mx="auto" px={{ base: 4, md: 8 }} spacing={4}>
          {/* Logo */}
          <Box w="32px" h="32px" borderRadius="full" bg="brand.primary" />
          <Text fontWeight="bold" color="brand.dark">Food Trace</Text>

          <Spacer />

          {/* Auth buttons */}
          {session ? (
            <Button
              variant="ghost"
              size="sm"
              onClick={() => signOut({ callbackUrl: '/login' })}
            >
              {session.user.name || session.user.email} • Logout
            </Button>
          ) : (
            <Button
              as={NextLink}
              href="/login"
              variant="ghost"
              size="sm"
            >
              Login
            </Button>
          )}
        </HStack>
      </Box>
      ...
    </Flex>
  );
}
```

### Session Data Available

From `next-auth.d.ts`:
- `session.user.name` - User's name (may be null, fallback to email)
- `session.user.email` - User's email
- `session.user.role` - User's role (PLATFORM_ADMIN, COMPANY_ADMIN, etc.)

### Edge Cases

| Case | Behavior |
|------|----------|
| Session loading | Show "Login" button (then switch when loaded) |
| Name is null | Display email instead |
| Multi-tab logout | NextAuth handles session sync automatically |
