# Story 7.8: Retailer Dashboard

## Status

**Pending**

## Story

**As a** retailer,
**I want** to see products in my custody and add trace records,
**so that** I can document receiving, stocking, and selling products to consumers.

## Acceptance Criteria

### Product List (Same as 7.6)
1. Dashboard page passes userRole and companyId from session to page component
2. Dashboard fetches products from GET /api/products?owner=me on mount
3. Loading spinner displays while products are being fetched
4. Empty state displays helpful message when no products
5. Product cards display: name, origin, blockchainId, harvest date
6. Products sorted by most recent first
7. Responsive layout (mobile, tablet, desktop)
8. Error state with retry option

### Trace Features (Same pattern as 7.7)
9. Each product card has "Add Trace Record" button opening modal
10. TraceRecordForm shows RETAILER actions: RECEIVED, QUALITY_CHECK, STOCKED, SOLD
11. Each product card has "View Timeline" button (expand/collapse)
12. TraceTimeline displays inline when expanded
13. "Receive New Product" section with ID lookup

### Retailer-Specific
14. Page title is "Retailer Dashboard"
15. Action dropdown includes STOCKED and SOLD options (not available to distributor)
