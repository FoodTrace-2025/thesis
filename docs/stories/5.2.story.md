# Story 5.2: Product Registration API Endpoint

## Status

**Draft**

## Story

**As a** backend developer,
**I want** to implement the product registration API endpoint,
**so that** producers can submit product data through the web interface and have it recorded on the blockchain.

## Acceptance Criteria

1. POST `/api/products/register` endpoint created
2. NextAuth.js session validation (user must be authenticated)
3. User role validation (only PRODUCER role can register)
4. Company wallet decryption using Epic 3 Tier 1 functions (decryptWalletKey)
5. Server-side transaction signing using company custodial wallet
6. Gas estimation before transaction submission
7. Transaction submission with retry logic (3 attempts on network failure)
8. Transaction receipt verification (wait for 1 block confirmation)
9. Product metadata saved to Supabase Product table (off-chain)
10. QR code SVG generated with URL format `https://foodtrace.app/trace/{productId}`
11. Transaction hash and productId returned to frontend
12. Audit log entry created (action: PRODUCT_REGISTERED)
13. Input validation: name required, origin required, harvest date not in future

### Technical Specifications

**API Route Structure (from architecture/coding-standards.md):**

```typescript
// src/pages/api/products/register.ts
import type { NextApiRequest, NextApiResponse } from 'next';
import { getServerSession } from 'next-auth';
import { z } from 'zod';
import { ethers } from 'ethers';
import { prisma } from '@/lib/prisma';
import { decryptWalletKey, getEncryptionKey } from '@/lib/crypto';
import { authOptions } from '../auth/[...nextauth]';
import ProductRegistryABI from '@/contracts/ProductRegistry.json';

// Input validation schema
const registerSchema = z.object({
  name: z.string().min(1, "Name required").max(100),
  origin: z.string().min(1, "Origin required").max(100),
  harvestDate: z.string().refine((date) => {
    const d = new Date(date);
    return d <= new Date();
  }, "Harvest date cannot be in the future"),
});

type RegisterResponse = {
  success: boolean;
  productId?: number;
  transactionHash?: string;
  qrCodeUrl?: string;
  error?: string;
};

export default async function handler(
  req: NextApiRequest,
  res: NextApiResponse<RegisterResponse>
) {
  // 1. Method validation
  if (req.method !== 'POST') {
    return res.status(405).json({ success: false, error: 'Method not allowed' });
  }

  // 2. Authentication
  const session = await getServerSession(req, res, authOptions);
  if (!session?.user?.email) {
    return res.status(401).json({ success: false, error: 'Unauthorized' });
  }

  // 3. Get user with company
  const user = await prisma.user.findUnique({
    where: { email: session.user.email },
    include: { company: true },
  });

  // 4. Authorization
  if (!user || user.role !== 'PRODUCER') {
    return res.status(403).json({ success: false, error: 'Only producers can register products' });
  }

  if (!user.company || user.company.status !== 'APPROVED') {
    return res.status(403).json({ success: false, error: 'Company not approved' });
  }

  // 5. Input validation
  const parseResult = registerSchema.safeParse(req.body);
  if (!parseResult.success) {
    return res.status(400).json({
      success: false,
      error: parseResult.error.errors[0].message,
    });
  }

  const { name, origin, harvestDate } = parseResult.data;

  try {
    // 6. Decrypt wallet
    const encryptionKey = getEncryptionKey();
    const privateKey = decryptWalletKey(user.company.encryptedPrivateKey!, encryptionKey);

    if (!privateKey) {
      // Log audit entry for security
      await prisma.auditLog.create({
        data: {
          action: 'WALLET_DECRYPTION_FAILED',
          userId: user.id,
          companyId: user.companyId!,
          details: { error: 'Decryption returned null' },
        },
      });
      return res.status(500).json({ success: false, error: 'Wallet decryption failed. Contact admin.' });
    }

    // 7. Create blockchain transaction
    const provider = new ethers.JsonRpcProvider(process.env.ALCHEMY_SEPOLIA_URL);
    const wallet = new ethers.Wallet(privateKey, provider);
    const contract = new ethers.Contract(
      process.env.PRODUCT_REGISTRY_CONTRACT!,
      ProductRegistryABI.abi,
      wallet
    );

    // Convert harvest date to Unix timestamp
    const harvestTimestamp = Math.floor(new Date(harvestDate).getTime() / 1000);

    // 8. Estimate gas
    const gasEstimate = await contract.registerProduct.estimateGas(name, origin, harvestTimestamp);

    // 9. Submit transaction with retry
    let tx;
    let attempts = 0;
    const maxAttempts = 3;

    while (attempts < maxAttempts) {
      try {
        tx = await contract.registerProduct(name, origin, harvestTimestamp, {
          gasLimit: gasEstimate * 120n / 100n, // 20% buffer
        });
        break;
      } catch (error) {
        attempts++;
        if (attempts === maxAttempts) throw error;
        await new Promise(resolve => setTimeout(resolve, 1000 * attempts)); // Exponential backoff
      }
    }

    // 10. Wait for confirmation
    const receipt = await tx!.wait(1);

    // 11. Extract productId from event
    const event = receipt.logs.find((log: any) => {
      try {
        const parsed = contract.interface.parseLog(log);
        return parsed?.name === 'ProductRegistered';
      } catch {
        return false;
      }
    });

    const parsedEvent = contract.interface.parseLog(event);
    const productId = Number(parsedEvent!.args.productId);

    // 12. Generate QR code URL
    const qrCodeUrl = `https://foodtrace.app/trace/${productId}`;

    // 13. Save to database
    await prisma.product.create({
      data: {
        blockchainId: productId,
        name,
        origin,
        harvestDate: new Date(harvestDate),
        companyId: user.companyId!,
        createdByUserId: user.id,
        transactionHash: receipt.hash,
        qrCodeUrl,
      },
    });

    // 14. Create audit log
    await prisma.auditLog.create({
      data: {
        action: 'PRODUCT_REGISTERED',
        userId: user.id,
        companyId: user.companyId!,
        details: {
          productId,
          transactionHash: receipt.hash,
          gasUsed: receipt.gasUsed.toString(),
        },
      },
    });

    // 15. Return success
    return res.status(200).json({
      success: true,
      productId,
      transactionHash: receipt.hash,
      qrCodeUrl,
    });

  } catch (error) {
    console.error('Product registration failed:', error);

    // Log error for debugging
    await prisma.auditLog.create({
      data: {
        action: 'PRODUCT_REGISTRATION_FAILED',
        userId: user.id,
        companyId: user.companyId!,
        details: {
          error: error instanceof Error ? error.message : 'Unknown error',
        },
      },
    });

    return res.status(500).json({
      success: false,
      error: 'Product registration failed. Please try again.',
    });
  }
}
```

### Error Handling Strategy

| Error Type | Response Code | User Message |
|------------|---------------|--------------|
| Not authenticated | 401 | "Unauthorized" |
| Not PRODUCER role | 403 | "Only producers can register products" |
| Company not approved | 403 | "Company not approved" |
| Invalid input | 400 | Specific validation error |
| Wallet decryption failed | 500 | "Wallet decryption failed. Contact admin." |
| Blockchain transaction failed | 500 | "Product registration failed. Please try again." |

### Risks & Mitigations

| Risk | Mitigation |
|------|------------|
| Wallet decryption fails | Audit log entry, clear error message to user |
| Transaction rejected (gas) | 20% gas buffer, retry logic |
| Nonce conflict (concurrent txs) | ethers.js handles nonce automatically |
| Network timeout | 3 retry attempts with exponential backoff |
| Contract not deployed | Fail fast with clear error if PRODUCT_REGISTRY_CONTRACT missing |
